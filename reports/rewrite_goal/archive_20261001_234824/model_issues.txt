假设与数据不符之处
  1. P4/(6e)：有效误差 σ_eff（1.5–3 cm，取自会话末与融合 TSDF 的残差，声明"已包含部分位姿和重建误差"）给出 ≈±4–7 cm 的支持区间。
     状态层比较的是提取时冻结的物体几何与之后几秒的帧。数据集自身的位姿-深度配准误差随时间间隔增长（diagnosis/out_6）：
       dt=2 s：中位 1.0 cm，12.9% 的静态点 >3 cm，5.8% >5 cm；dt=4 s：1.5 cm，24.9%，13.0%；dt=8 s：3.2 cm，52.5%，33.8%。
     床（网格建于 ≤48.5 s）在其后两个 2 s 轮里的独立复算：实测-预测中位 +3.8 cm、+7.9 cm，f(5 cm)=0.34、0.71（代码报 0.43、0.66），f(10 cm)=0.03、0.13（diagnosis/out_5）。
     模型里没有随"几何刷新后经过的时间"增长的误差项。
  2. P6/(7)(7u)：正常整轮比例被当作平稳 Beta，且用本对象已见正常轮估计。本地 Beta 在样本 N=2 就取代初始化分布（README 自述"需检查小样本响应"）：
     柜 I2 t=133.4 s Beta(0.82,16.8) -> (17.83,2663)，随后普通的 f=0.019 得 z=7.8、LR=4.8e-5 并被关闭；背包 I14 Beta(16.18,1065)；衣柜 I6 Beta(18.74,6399) 使 f=0.044 的 l_in 下溢为 0（diagnosis/out_4）。
     有效射线 n<=5 的轮给出 LR 6e-12（显示器 I20，S=0/F=3）、3e-15（床，S=0/F=5）、2e-8（转椅 I10，S=1/F=3）（diagnosis/out_2），直接决定关闭。
  3. P2/(5)(5e)：先验强度 2，一个强反证轮把 E[v] 拉到 0.447（<0.5），1–3 轮即关闭；强反证轮 46/208 个，且在时间上成簇（125–130 s 同时 6 个物体，50–55 s 4 个），与相机转速无关（16.9 vs 17.4 deg/s）。

问题 MI-2：会话末现表面的面无法被判为"物体的面"（H_dup 的承诺门槛 α=0.01 与 README 给出的逐面似然比不相容），导致 object_faces=0，最终地图的物体层为空。
  代码对 README 原理 10（第 553–556 行）、α=0.01（第 479、231 行）的实现经逐项核对是忠实的（diagnosis_4.txt 第三节），问题在公式之间。

README 的规定
  · 第 479 行常数表：α=0.01，"任一二元承诺可接受的最大误承诺后验概率，全局唯一"，ln99；第 553 行：先验几率 π_dup/(1-π_dup) 由已承诺的配对结局估计，冷启动 π_dup=1/2，
    "按 (5e)，Pr(H_dup) ≥ 1-α 则两者合并"。
  · 第 553–556 行：同会话两份融合面的 H_dup 预测法向偏移 d ~ N(0,σ²)，σ² 取离散项（h²/12 之和，h=2 cm 时 σ≈0.82 cm），H_sep 预测 d 在 ±T 内无约束（T=2h=4 cm）；
    并声明这与旧规则"一体素内最近当前物体面"等价（关联管 1.9–2.5 cm）。

数值（diagnosis/dup_max_logodds.py，输出 out_10）
  · 单个面的 H_dup 对 H_sep 的最大对数似然比（偏移 0）= -ln(σ√2π) + ln(2T) = 1.359（BF 3.89），小于 ln99 = 4.595。
  · 要达到需要 σ ≤ 0.32 mm，或先验赔率 ≥ 25.4（π_dup ≥ 0.962）；而 π_dup 只随"已提交的配对结局"增长，冷启动为 1/2，没有任何一次提交，因此循环不可达。
  · 旧规则是没有证据门槛的硬关联管；加上 α 门槛后等价关系不成立。
