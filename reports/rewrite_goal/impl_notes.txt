3. README did not fix these; the most direct reading was implemented
------------------------------------------------------------------
a. chi(c): the declared table is backend.high_mobility_semantic_labels; listed classes chi=0, every
   other class (including unknown, label -1) chi=1.
b. A round is "normal" (enters calibration) when it was judged compatible (omega > 1/2) and did not
   end the placement; it is calibrated after the decision, so the decision used the earlier model.
c. Population statistics are updated round by round in identity order; the old per-pass freezing of
   the population was not carried over (README does not state it).
d. Evidence sources: surface samples = triangle centroids (points for a topology-free mesh), one per
   cell of the map resolution (Backend::object_surface_resolution_), no budget cap. One (frame,pixel)
   is one source. The round window is (watermark, latest] and not before the placement's birth.
   Assumption: session clocks are monotone across sessions (as birth_time already requires).
e. Classification (rationale in 8 below). It uses the midpoint density of the coded bin (README (12): O(u^2) approximation), which
   gives a closed-form support interval per query: an echo is supported while the normalised Gaussian
   density is at least the uniform first-hit density, i.e. |e| <= sigma sqrt(2 m) with m = log of the
   density ratio at zero residual. The exact bin integral is not used.
f. Pending observation absorption (5b): kept as the time rule "actual support time inside the
   observation's acquisition interval"; the class and shared-surface conditions are gone.
g. Static frame selection (P5): the numeric cut is gone (three static_consistency_* config fields and
   test_static_surface_consistency removed). The extractor now reads the placement attribution, see 9.
   RISK: a single extraction that spans a hidden move before the registry has decided is not split;
   the registry only knows a closure after its evidence round.
h. Surface retention: keep model = (1-f) Gaussian + f uniform-beyond, f = population mean of the
   normal fraction (1/2 for the neutral Beta(1,1)); remove model = uniform beyond the query.
   Occluded echoes give 0. Footprint = pixel rays within the element's extent (its layer half
   voxel); model constants are computed at the element's own range once per frame.
   Priors: historical face = E[v] of the identity's current placement, background = initial mean
   0.67; a session candidate (fill) starts symmetric and needs strictly positive evidence.
   A historical face of the same identity explained by the present surface (distance <= the reach at
   which the Gaussian of the combined uncertainty is as likely as a uniform position on (-T,T))
   is dropped (P9: no independent output identity).
   Uncertainty of a face = posterior standard deviation 1/sqrt(sum 1/sigma^2 of supporting echoes).
i. Effective error model psi (sigma per 0.5 m bin, zeta): restored from evidence_state.cbor, else
   read from backend.error_model_path (sigma_cm and depth_scale of the same object, e.g.
   sensor.sigma_cm / sensor.depth_scale), else the run is rejected. configs/room18_instance_5cm.yaml
   points to the file the README names,
   /home/jixian/Desktop/FT/runs/unify16_20260929/a/session_a/refusion_report.json (it exists; the
   first version of these notes said it did not, which was wrong, and the loader read depth_scale
   from the top level only, so zeta came out 0; fixed in the CODE_FIX round). At session end the
   new estimate replaces psi for the next session (bins without an estimate keep the previous
   value). Predictions of the current session use the previous psi (README (6m)).
j. Missing valid measurement is the unit factor; an uninformative round never ends a placement.
k. (5b) death time keeps the single upper bound d = max(t, s_f) for the single-time interface (the
   presence interval); the change interval is recorded separately, see 9.

[1] zeta: FIXED where it has an exit. depth_scale is read from the object that holds sigma_cm
    (sensor.depth_scale = 0.0394 for the default model). In the session-end retention, a
    historical element is echoed at (1+zeta_previous)/(1+zeta_now) times its range (zeta_now is this
    session's fit), so the estimated scale shifts the expected echo. Online (state rounds) both the
    stored surface and the echo are raw readings of the same sensor and psi.zeta is the only scale
    known, so the ratio is 1 there; applying zeta as a signed bias to a raw-built map would shift
    every comparison by ~4 % of the range. b_psi is therefore expressed through zeta, not as a
    separate stored bias. The scale of a stored surface is taken as the previous session's zeta
    (psi.zeta at load); the radial rescaling about the new camera is an approximation.
[2] P5: IMPLEMENTED as far as the registry knows: FrameAttribution (session_core/state) carries, per
    identity, the latest actual support of its closed placements (w_closed of (5b)); the extractor
    excludes frames at or before it (selectStaticFrames). Not solved: frames of a hidden move that
    the registry has not yet decided are still fused (see 3g).
[3] change interval: IMPLEMENTED. The earliest valid contradiction after the last support is kept
    on the placement (first_contradiction, reset by a later support, persisted in the registry
    checkpoint). A closed state's node carries session_change_after / session_change_before
    (latest actual support, first valid contradiction, or the decision time when there is none).
    The presence interval keeps the decision time as the upper bound (single-time interface).
[4] frame count: IMPLEMENTED. The extractor writes the acquisition times of the distinct frames
    (reconstruction_frame_stamps); fragments hold the sorted keys, merges take the union, the count
    is their number; keys are persisted in the checkpoint and in the node details. A fragment of an
    older map keeps its stored count (sum on merge).
[5] see 5: precision of an explained historical face is added to the present surface; an
    oppositely oriented face is not merged (P9: thin plates). Full fusion NOT done.
[6] see 5, no change.
[7] see 5, not changed (scope).
[8] classification alternative densities. README (6e) gives the Gaussian of a normal echo and says
    the density is normalised on the device range, and (12) needs p(r | remove). It does not define
    the density of an echo when the surface is absent. The first-hit model of P4 (H_j = o_j prod
    (1-o_k)) says an absent surface leaves the first hit to another, unknown surface, so the
    alternative is a first hit at an unknown distance: uniform on the device range (the density
    with no information), before the query (occluded) or after it (penetration). Equal priors and
    a tie to support follow P3 (symmetric unit loss, a tie continues the existing interpretation).
    The half width sigma sqrt(2 m) therefore depends on r_min and r_max by construction of (6e)'s
    normalisation. No other choice is implied by the README; kept, recorded here.
[9] constants outside the table: kept and named in 4 (existing effective residual estimator that
    the README reuses for the sigma curve; 64 frames / 16 px are computational sampling of (9b);
    the correspondence gate is the background truncation of the layer). The README says those
    values have no derivation but also says to reuse the existing effective error curve and to
    keep estimating it in the session, which needs a binning and a sample gate.
