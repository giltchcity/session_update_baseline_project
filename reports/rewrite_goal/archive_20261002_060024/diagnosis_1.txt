三、原因类别
  1（实现偏离 README：γ̂(0⁺) 与下端外推，对应 README 式 (9v)、第 486 行 σ_s 的 Δt→0 极限、第 474 行外推规则）
  + 2（数据流：h_o 的 Δt_f 与变差函数的最小时差都来自间隔 ≥0.4 s 的证据流，而 README 的 Δt_f 是被融合帧的相邻间隔）。
  不是 README 模型问题：README 的公式用它自己的定义套到代码自己测得的数据上，得到 2.02 cm，与它自己写的 1.8–2.0 cm 一致。

四、按 README 应该怎样才对（不是为指标加特例，也不是调参数）
  1. γ̂(0⁺) 是变差函数在 Δt→0 的极限，σ_s(ρ,θ)（"Δt→0 极限"）同理：最小已测时差不为 0（此处 0.4247 s）时，按 README 自己的规则把变差函数线性外推到零时差，
     σ̂²_reg(Δt) = γ̂(Δt) − γ̂(0⁺) 在第一个已测时差处为正，而不是被定义为 0；或者让相邻帧的重测对（Δt≈0.033–0.1 s）进入变差函数。二者择一，都是 README 的定义。
  2. h_o = √12·σ_eff(Δt_f) 里的 Δt_f 是被融合那条帧流（会话末重融的帧档案）的相邻帧间隔，在提取时用当时的估计取值；不是证据存储的最近间隔。
  3. 改完后的验证（我会按锁定协议重跑）：refusion_report.json 的 voxel 应在 README 的 1.8–2.0 cm 附近（约 0.020），G1 F1@5 回到基线 −0.2 pp 以内。
     若 voxel 对了而 G1 仍不达标，则剩余差距是另一个原因，另行诊断。
