## 1. 系统目标与完整递推

D1 是持续可见的运动，D2 是同一运行内的隐藏变化，D3 是跨 session 空档的隐藏变化。每个 session 启动新进程和短期跟踪器，恢复前序地图后继续执行完整 D1/D2。

设会话输入为 \(Y_k=\{(t_i,I_i,D_i,L_i,T_i)\}_{i=1}^{n_k}\)，分别包含时间、颜色、深度、物理身份和相机位姿；语义类别另行保存。持久状态为 \(P_k\)。完整算法的组合为

\[
\boxed{
P_k=\operatorname{Save}\!\left[
\operatorname{Surface}\!\left(
\operatorname{Drain}\!\left[
\operatorname{Fold}_{Y_k}(\operatorname{Khronos}+\operatorname{IdentityEvidence},
                         \operatorname{Load}(P_{k-1}))
\right],Y_k\right)\right].
\tag{1}
\]

式中 `Khronos + IdentityEvidence` 表示已有在线执行链在确定的回调点组合项目扩展。`Drain` 排空处理队列、异步变化检测和最后到达的物体片段；`Surface` 用最终状态限定观测，再更新会话末表面；`Save` 提交下一进程读取的状态。

初值 \(P_0=\varnothing\)，同一运行入口完成 \(P_0\to P_A\to P_B\to P_C\)。下一会话读紧邻前序状态；旧 session 的完整输入视频和整条快照序列留在原产物中。

研究验收同时衡量三个目标：

\[
Q_{\rm current}(A\to B)\ge Q_{\rm current}(B),\quad
I_{\rm persistent}(A\to B)>I_{\rm persistent}(B),\quad
\operatorname{Ghost}_{\rm current}(A\to B)=0.
\tag{2}
\]

这是评价目标。准确度按真实 RGB-D/GT 检查，信息增益来自未重观测区域的保留、静态多视角补全和时间历史。移动物体旧状态进入 HISTORY，新位置进入 CURRENT；全过程和最终时刻分别检查。

### 1.1 统一模型：一个测量似然、一个持续性先验、一个决策准则

本节先写完整的推断问题，再说明现有每个状态机制是其中哪一项，最后用同一组量解释五个必须同时成立的场景。逐条试验的数值、回退理由和对照记录在 `reports/rewrite_goal/patch_list.csv` 及其引用的 JSON；README 只保留模型与公式。

**状态与三个解释。** 对物理身份 \(\ell\)，已提交的 CURRENT 状态记为 A（几何 \(G_A\)、开始时间、最后实测支持）；本会话尚未与 A 关联的同身份观测记为 N（同会话为 `observed_new`，继承态为会话子状态 `b_session` 的 CURRENT）；其余片段是 HISTORY。一次**观测事件** \(e\) 是一轮变化检测：冻结一份到 \(t_e\) 为止的证据快照，依次执行验证、摄取/物化，终局时再执行终结。对 A 与 N 只有三种解释：

- \(S\)：A 仍在原处，N 是 A 的其他表面（另一面、补全）；真实当前几何为 \(G_A\cup G_N\)。
- \(M\)：A 已结束，N 是继任状态（或继任尚未被观测到）；真实当前几何为 \(G_N\)。
- \(U\)：N 不是 \(\ell\) 当前状态的有效重建（轮廓碎片、偶发错标）；真实当前几何为 \(G_A\)。

**测量似然。** 全部推理以同一批有时间和来源的实际 RGB-D 测量为条件：

\[
\mathcal L_t(X_t)=p(Y_t\mid X_t,Y_{<t})
=\sum_{a,v,z}\int p(Y_t,a,v,z\mid X_t,\Theta)\,
 p(\Theta\mid Y_{<t})\,d\Theta . \tag{M1}
\]

\(a\) 是测量与状态/表面的对应，\(v\) 是可见、遮挡、未覆盖等观测条件，\(z\) 是表面样本是否可靠，\(\Theta\) 是深度误差、标签漏检和样本可靠性参数。深度项是同一首回波模型：令 \(\rho_a(X)\) 为射线与假设表面 \(a\) 的距离，\(F_q\) 为该量程下测距残差分布，\(h\) 为表面离散半尺度，

\[
g_{q,h}(e)=\frac{F_q(e+h)-F_q(e-h)}{2h},\qquad
p(r,\widehat\ell\mid X,\Theta)
=\sum_a\pi_a(X)\,g_{q,h}\!\left(r-\frac{\rho_a(X)}{1+s}\right)
 Q(\widehat\ell\mid\ell_a,r,a). \tag{M1a}
\]

\(\pi_a\) 含足迹内对应与首回波可见性，\(Q\) 是已关联端点的身份识别/漏标。遮挡由更近表面生成回波，被遮挡表面的状态被积分掉，似然比为 1；视野外和无效读数同样为 1。现有代码把同一批读数分成互不重叠的四组摘要，每组对“M 对 S”给出一个似然比；相加时同一读数只用一次：

| 组 | 读数 | 似然比 | 现有计算 |
|---|---|---|---|
| \(Y_A\) 旧址 | A 最后支持之后投影到 \(G_A\) 的读数 | \(\Lambda_A\) | 端点关系 M1m；可靠样本看穿比例的单侧 Beta/均匀序贯似然比 (7)；同一批射线的支持票 \(S\)、反证票 \(C\)；区间有限样本似然 M1e |
| \(Y_N^{\rm geo}\) 新几何 | N 的表面相对 \(G_A\) 的位置 | \(B_{M:S}\in[0,2]\) | 共享支持 M1c、范围 M1d、离址比例 M1g 与有效格数 → M1h |
| \(Y_N^{\rm cov}\) 新覆盖 | N 的可靠空间样本数 \(n\) | \(e^{\ell_E}\) | 泊松覆盖强度的轮廓似然 M1f：N 是否已重建成能承载身份的表面 |
| \(Y_{D1}\) 跟踪 | 原生跟踪器运动标志 | \(\infty\) | 原生只输出布尔值，按其定义作为确定的换状态观测 |

\(Y_A\) 与 \(Y_N\) 来自不同位置的像素；\(Y_N^{\rm geo}\) 与 \(Y_N^{\rm cov}\) 回答同一 N 的两个不同问题（在哪里、是否已建立），所以 M1c/M1d/M1g 不在同一判定中相乘，覆盖似然也不加到方向赔率上。对可靠表面，在位穿透率 \(f\sim{\rm Beta}(\alpha,\beta)\) 时有限覆盖的计数似然为

\[
p(k\mid n,S)=\binom nk\frac{B(k+\alpha,n-k+\beta)}{B(\alpha,\beta)},
\qquad p(k\mid n,M)=\frac{1}{n+1}, \tag{M1b}
\]

后者是原 absent 均匀比例模型。现有 (7) 用连续比例的 Beta 密度并作单侧处理；它是受保护的序贯检验，只解释不改写。

**持续性先验。** 对身份 \(\ell\)，\(q_\ell\) 是相邻两次有效观察之间换状态的概率，\(K_\ell\) 是换状态后的分布：

\[
p(X_{\ell,t}\mid X_{\ell,t-1},q_\ell)
=(1-q_\ell)\,\delta_{X_{\ell,t-1}}(X_{\ell,t})
+q_\ell K_\ell(X_{\ell,t}\mid X_{\ell,t-1}). \tag{M2}
\]

延续允许新测量补全该状态的几何；\(K_\ell\) 只接收新状态自己的观测，不把旧形状搬到新位置。每身份同一时刻至多一个 CURRENT，历史不并入另一状态，未来测量不支持过去。没有有效观测时不推进一次变化试验。类别、物体自身历史通过层次 Beta 进入同一个 \(q\)：同类其他物体给 \((m_c,u_c)\)，同组其他类别给 \((m_g,u_g)\)，物体自身已解决的关系给 \((m_\ell,u_\ell)\)（`closeCurrent` 记变化 \(m\)，确认吸收或终局同状态记延续 \(u\)；D1 首片段单记一次变化），类别名单只作一条方向意见 \(o c\)：

\[
\mu_g=\frac{m_g+1/2+oc}{m_g+u_g+1+o},\quad
 a_c=\kappa\mu_g+m_c,\quad b_c=\kappa(1-\mu_g)+u_c,\quad
 q_\ell=\frac{a_c+m_\ell}{a_c+b_c+m_\ell+u_\ell},\quad \kappa=1+o.\tag{M2a}
\]

\(1/2\) 是 Bernoulli 的 Jeffreys 参考测度；冷启动可动类均值 3/4、持续类 1/4，无类别表 1/2。**读取时刻**：\(q_{\ell,e}=E[q_\ell\mid H_{<e}]\)。同一事件内所有身份、所有动作读同一份事件前历史；本事件解决的关系只对后续事件可见。物理 ID 编号、遍历顺序、同一时刻的重复回调和会话结束都不是测量，不能改变 \(q\)。P09 第三次试验（7cd19e7）实现了这一读取时刻：每轮变化检测开始时冻结各身份已解决的变化/延续计数与类别，验证、摄取/物化和终结都读该快照，本轮解决的关系只对下一轮可见。此前终局遍历先处理的身份立即写入类别历史，交换两物体编号即可让 \(q\) 由 0.75 变 0.5（P01_P09_identity_renaming_trace_20261004）；修正后该编号置换不变。验收（P09_attempt03_20261004）：25 项测试、编号置换快例不变、生命周期快例不变；真实 B 92 条逐身份决策流中 90 条与对照逐值一致，另 2 条只是 I2 首个 B 片段早一轮到达（与 P07、P09 第二次记录的异步到达相同），806 次依赖 q 的判定按日志重算无一翻转；合成 B 255/255、3RScan 34/34、Bonn 三段与 TUM 全部一致；固定指标全部在 48a3033 的 0.2 个百分点内（真实 B 物体召回 98.07%）。

**决策准则。** 每个动作取后验期望损失最小：

\[
\pi_t(X)\propto\mathcal L_t(X)\int p(X\mid X',q)\pi_{t-1}(X',q)\,dX'\,dq,
\qquad a_t^*=\arg\min_{a\in\mathcal A(X)}\mathbb E_{\pi_t}[C(a,X)]. \tag{M3}
\]

对二假设，\(\frac{P(M\mid Y)}{P(S\mid Y)}=\frac{q_\ell}{1-q_\ell}\frac{p(Y\mid M)}{p(Y\mid S)}>\frac{C_{MS}}{C_{SM}}\)。 \tag{M4}

损失只有一张表，两类条目：
- **关联与显示**：显示表面与真实当前表面的对称差，同一表面测度、单位损失。设 \(a=\mu(G_A\setminus G_N)\)、\(b=\mu(G_N\setminus G_A)\)，三种显示的风险为 \(R_{\cup}=p_Ma+p_Ub\)、\(R_{A}=p_Sb+p_M(a+b)\)、\(R_{N}=p_Sa+p_U(a+b)\)，于是 \(R_A-R_\cup=(1-2p_U)b\)、\(R_N-R_\cup=(1-2p_M)a\)：只有 \(p_U>1/2\) 才只显示旧址，只有 \(p_M>1/2\) 才只显示新址，否则显示并集。比较边界是后验 1/2，即 M4 中损失比 1。
- **无继任观测而结束状态**：只凭旧址读数把身份从 CURRENT 删去，与“继续保留”的损失比 99:1，来自既有缺席检验的名义 1%/1% 错误预算（282573a），是声明的损失比而非由数据拟合。

代码中所有判定边界都是这两条损失比在 M4 中的结果：\(\log 99\)、\(q B>1-q\)、\(1-q\ge qB\)、多数票。

**由同一准则得到的动作。**

1. **旧址看空即结束 A**（S12/S13/S14，式 5）：受保护的 CUSUM 过 \(\log99\)，再由同一批射线的反证多于支持确认。多数票是对称投票模型下精确的后验符号：反证 \(C\)、支持 \(S\) 的对数似然比为 \((C-S)\log[p/(1-p)]\)，对任何票可靠度 \(p>1/2\) 只取决于 \(C-S\)。两摘要来自同一批射线，取“二者都成立”而不相乘。
2. **接任**（A→HISTORY，N→CURRENT）：继承态要求 N 已建立 \([\operatorname{logit}q+\ell_E>0]\) 且 \(qB_{M:S}>1-q\)（M1f/M1h）；同会话要求 N 在异址 \(q(1-p_{\rm ext})>(1-q)p_{\rm ext}\)（M1d）且旧址本轮无同身份支持。在“一身份一处”约束下，M 时同身份端点不可能落在旧面上（N 与旧址重叠的情形由 M1e 单独处理），一票支持即排除 M；\(S=0\) 是这一约束给出的条件，不是可调门槛。
3. **合并**（N 并入 A）：A 本轮有实测支持且未被看空时吸收 N，需 \(1-q\ge qB\)（M1k/M1l）；同会话摄取用共享支持 M1c，并排除区间内被看空的旧状态（M1e）。
4. **显示**（每个在线输出的物化）：显示可在下一输出修改，不是提交，应直接取上面的贝叶斯显示：\(S\) 为 MAP 显示 \(G_A\cup G_N\)；A 已被看空、或 \(M\) 为 MAP 且 N 能承载身份时显示 \(G_N\)；\(M\) 为 MAP 而 N 已测得未建立（碎片，\(U\) 占优）时只显示 \(G_A\)。现有 M1i 在 \(S\) 为 MAP 时显示并集，其余情况一律只显示 \(G_A\)：它把“尚未测覆盖的继任片段”和“A 已被看空”也当成 \(U\)，使已观测到的新址晚一个输出出现、旧址多留一个输出；这一差别是 P08 第二次试验。
5. **终局**：同一后验、同一规则；会话结束不是测量。先执行已成立的看空与接任，再按 \(1-q\ge qB\) 合并；剩余 \(M\) 为 MAP 而未建立的 N 归档为 HISTORY，不删除、不并集（S18）。

**已实现的各项（公式与条目）。** 每项的逐物体对照和验收见 patch_list 对应行。

- P01（M2a）：`isHighMobility` 的三条 OR 改为同一个 \(q\)；类别名单只给先验方向。
- P02（M1c）：共享体素的量化相位对应概率 \(p_{xy}=\prod_j(1-|x_j-y_j|/r)_+\)，\(p_\cap=1-\prod_v(1-\max_w p_{x_vy_w})\)；同状态当且仅当 \((1-q)p_\cap>q(1-p_\cap)\)。
- P03（M1d）：AABB 间隙无格界事件 \(p_{\rm ext}=\prod_j(1-g_j/r)_+\)；异址当且仅当 \(q(1-p_{\rm ext})>(1-q)p_{\rm ext}\)。
- P04（M1e）：区间内可靠样本的有限样本缺席似然 \(\ell_i=w_i[-\log(n_i+1)-\log p(k_i\mid n_i,S)]\)，单侧；旧址被看空当且仅当无同身份支持且 \(\operatorname{logit}q+\sum_i\ell_i>\log99\)。

- P07（M1h）：离址比例 \(f\) 与有效格数 \(n_{\rm eff}=N^2/\sum_cN_c^2\)，\(S\)：\(\theta\in[0,1]\)，\(M\)：\(\theta>1/2\)，同一 Jeffreys 参考测度，\(B_{M:S}=2P_{{\rm Beta}(1/2+n_{\rm eff}f,\,1/2+n_{\rm eff}(1-f))}(\theta>1/2)\le2\)。

## 3. 身份、状态与时间

每个物理实体 \(\ell\) 有独立于语义类别和 DSG node ID 的身份。实体的运行状态写作

\[
X_\ell=(\mathcal F_\ell,c_\ell,n_\ell,b_\ell,\mathcal A_\ell,\eta_\ell).
\tag{3}
\]

\(\mathcal F\) 保存时序片段；\(c\) 为 current；\(n\) 为候选；\(b\) 为继承实体的本会话子状态；\(\mathcal A\) 是已摄取观察区间；\(\eta\) 保存观测统计及运动先验。一个片段包含几何、包围盒、语义、出生、最近支持、传感器确认和关闭时间。

时间有明确角色：观察时间来自传感器；状态开始时间限定观测有效域；裁决时间标识执行轮次。合并片段时出生/首次观察取最早，支持/确认取最晚。关闭时间为

\[
t_{\rm close}=\max(t_{\rm decision},t_{\rm last\ support}).
\tag{4}
\]

片段按 `(first,last,node_id)` 摄取；重复区间在入口识别。首个观察打开 current。带可见运动历史的观察关闭原片段并打开新片段。继承实体先把本会话观察送入 \(b\)，让旧位置与新位置分别接受证据。同一会话内，体素重叠且其后仍有表面支持的观察可加入 current，其余进入候选。

设本轮支持数 \(S\)、反证数 \(C\)、可靠缺失门 \(g\in\{0,1\}\)，有效反证 \(C^*=gC\)。候选与 current 的扩张包围盒分离指示为 \(D\)。普通 current 的关闭条件为

\[
J=[C^*>S]\lor[D\land S=0].
\tag{5}
\]

`candidateWithinCurrentExtent` 实际检验两个世界 AABB 在一格容差下是否相交（不是候选完全包含于 current）。这个粗对应检验防止衣柜另一面或原位调整独自触发交接；它属于 M1 的同站点似然近似。式 (5) 的两条路径分别保留“旧位置确实被看空”和“同身份已在另一处被观测且旧址无支持”的需求。

关闭时提升可用候选；有直接支持时更新确认时间。候选出生不晚于支持且 \(1-q\ge qB\)（M1k/M1l）时合入当前片段。

继承状态还使用本会话已建立的实体几何：本会话可靠样本给出建立后验 \(\operatorname{logit}q+\ell_E>0\)（M1f），且离址几何因子满足 \(qB_{M:S}>1-q\)（M1g/M1h）时，判定实体已在另一位置。此项与式 (5) 的有效反证共同驱动继承态退出；本会话 current 接任。\(q\) 由 M2a 给出，类别、D1 历史和已关闭片段只通过它进入。

终结按相同规则处理候选和本会话子状态，再把最后的状态物化进 DSG。几何合并执行当前基准的网格拼接；实体时间片段与几何存储分别保持各自含义。

源码：`session_core/src/state/persistent_object_state.cpp`、`src/adapters/physical_object_merge.cpp`、`src/adapters/backend_session.cpp`。

## 4. 同一测量的几何含义与物理证据

相机中心为 \(c_i\)，世界射线方向为 \(d_i(u)\)，径向测距为 \(r_i(u)\)。测量端点为 \(p_i(u)=c_i+r_i(u)d_i(u)\)。查询旧点 \(x\) 时

\[
q_i(x)=\|x-c_i\|,\qquad e_i(x)=r_i(\pi_i(x))-q_i(x).
\tag{6}
\]

光轴 Z 深度由相机模型转换到径向距离后比较。世界变换统一左乘；几何和测量使用同一坐标系。点证据使用式 (6)，体素积分使用其投影像素方向上的 projective 残差。

| 实测关系 | 物理实体证据 |
|---|---|
| 视野外或无有效深度 | unobserved |
| 测量在旧点前方 | occluded |
| 深度吻合且相同物理 ID | supported |
| 深度吻合且其他 ID / 背景 | replaced by other / background |
| 射线穿过旧点到达更远表面 | free space |

几何存在性允许任意身份的同位置测量提供支持；实体存在性同时检查物理身份。查询使用状态最后支持之后的实际测量；遮挡与视野外各自保留为观察条件。

物体样本按空间格去重，维护各样本的支持与穿透时间。可靠样本上的观空比例 \(f\) 由自身与总体历史拟合 \(p_{\rm present}(f)\)（Beta 密度），当前实现递推

\[
L^+=\max(0,L-w\log p_{\rm present}(f)),\quad
w=\min(1,N_{\rm fresh}/\max(1,N_{\rm reliable})),\quad
 g=[L^+>\log99].
\tag{7}
\]

式 (7) 已经是以 absent 的均匀密度为参照、以 present 的经验 Beta 密度为分母的单侧加权 CUSUM。\(\log99=\log((1-0.01)/0.01)\) 源于原实现的 Wald 错误预算；CUSUM、鲜样本权重、经验拟合和单侧裁剪共同构成现有近似。该来源不等于在相关表面样本上已证明严格 1% 错误率。保留此递推与阈值，只解释，不重造检验。其输出授权式 (5) 的反证进入裁决。通过后重置累计量；传感器总体统计随会话保存。标签统计保留在证据记录中，当前覆盖门使用几何项。

关闭物体对应的背景副本由 `closed_object_background.cpp` 查询实际后续深度：背景表面自身时间参与查询，同位置实测表面继续提供支持，最后几何支持之后的穿透才产生背景变化。静止物体同时参与背景和 private mesh 的既有表示由此协同更新。

## 5. 状态授权的会话末观测域

令 \(t_\ell\) 为本会话新开的当前状态首次观察时间，恢复基准从 registry 的 `track_first_seen` 读取，缺值时取 `birth_time`。早于 \(t_\ell\) 的本身份像素退出当前状态的融合。其他旧像素保留实测端点，自由空间受到当前物体首交 \(\lambda\) 限制。

体素积分设截断距离 \(T\)、projective 残差 \(\delta\)，测量的合法贡献域为

\[
\delta>-T\quad\land\quad(\delta\le T\ \lor\ \widetilde q<\lambda-T).
\tag{8}
\]

\(\widetilde q\) 是体素沿采样射线的投影距离。\(\lambda\) 先查当前物体三角面，缺少合格命中时使用实测端点体素首交。式 (8) 保留观测表面的局部带和当前物体之前的自由空间。

合法贡献进入会话末 `PresentTsdf`：

\[
F^+(x)=\frac{W(x)F(x)+\min(1,\delta/T)}{W(x)+1},\qquad W^+(x)=W(x)+1,
\quad P=\operatorname{MC}(F=0).
\tag{9}
\]

只在八角均已积分的 cube 提取表面。这里的 `PresentTsdf` 是既有会话末模块；在线融合继续调用 Khronos。新面按面心到当前物体三角面的最近距离关联身份，一个物体体素内继承对应物理 ID，其余归背景。

表面公差使用 \(\tau(h,q)=\max(h,\sigma(q))\)，\(h\) 是层体素的一半；\(\sigma\) 由当前表面与测量的距离分箱残差估计。跨视图深度尺度 \(s\) 由残差的稳健中位数拟合，当前与历史尺度共同定义旧表面的位移误差窗口。

这里的 \(\sigma\) 是“读数相对当前重建表面”的条件残差尺度：只统计前向、深度有效且位于既有截断域内的绝对残差。当前表面也由这些深度构建，因此它不是已分离出来的独立传感器噪声；同一像素对应多个顶点时，直方图条目也不是独立测量数。R08 的半体素下界保护粗网格表面，max 保留两种误差保护作用，但尚不是卷积后验。推广 P37–P42 时须保留这种相关性和选择条件，不能直接把现有 \(\sigma\) 再与网格误差独立相加，或把它充当 P05–P08 的新片段可信度。源码、谱系及不可辨识反例见 `reports/rewrite_goal/C3_joint_calibration_contract_20261004.json`。

源码：`session_core/src/surface/session_refusion.cpp`、`present_tsdf.cpp`、`triangle_grid.cpp`、`frame_archive.cpp`。

## 6. 旧表面延拓与一次装配

当前恢复基准对带身份、来源和时间的旧表面执行以下明确判定。直接表面支持 \(H\)、有效穿透 \(F\)、遮挡 \(B\)、截断带内遮挡 \(B_T\) 均来自第 5 节观测域。投影邻域的命中取有效支持，穿透要求有效采样均穿透；自由空间同时检查 \(\lambda\)。

直接观测的延拓条件写为

\[
K_{\rm obs}(x)=
\begin{cases}
[H\ge F],&H+F>0,\\
[B\ge2B_T],&H=F=0.
\end{cases}
\tag{10}
\]

平票和零证据延续旧表面。对旧点 \(x\)，设当前表面最近点 \(y\)、距离 \(d\)、最近有效 reaching 相机 \(c\)、量程 \(q\)，历史正尺度最大值为 \(s_A\)，本会话正尺度为 \(s_B\)。错位副本条件为

\[
D(x)=[s_A+s_B>0]\land\operatorname{reached}(x)
\land[2h<d\le\tau(h,q)+(s_A+s_B)q]
\land[(y-x)\cdot(c-x)>0].
\tag{11}
\]

它检验视线方向、当前表面对应与尺度误差窗。几何存储中精确相同的点面可以共享表示；式 (11) 则会改变表面选择，属于算法判定。

同身份内部判定用于已进入视野且离当前表面超过一个物体体素的旧点：沿固定 64 个方向查同 ID 当前表面的首交，按面法向计入 \(N_{\rm in}\)、\(N_{\rm out}\)，取

\[
I(x)=[N_{\rm in}>N_{\rm out}].
\tag{12}
\]

有 shown memory 时，旧面保留位为

\[
K(f)=\operatorname{stateValid}(f)\,
K_{\rm obs}(\operatorname{center}f)\,[\neg D(\operatorname{center}f)]
\prod_{v\in f}[\neg I(v)].
\tag{13}
\]

`stateValid` 对背景成立；物体要求 current 存在且该状态始于本会话之前。旧图只有推理几何时，恢复基准的后备路径对其中 memory 顶点执行内部判定，再与新表面装配。

本会话在线几何还提供 fill 候选：面心 cube 存在未积分角，且面心有实测支持时保留。最终几何按 fill、present、保留旧面的顺序装配，身份决定输出槽；属性按来源保存，新增顶点从同槽原几何取属性并截时。物体输出槽为空时保留输入槽，背景直接提交。全部结果先计算到局部数据，再写入最终地图。

式 (10)—(13) 保留当前恢复版的直接测量、近邻遮挡、错位副本及内部面判定。它们分别近似 M1 中的观测或对应关系，再由 M3 决定表面去留。推广必须逐项保留其真实需求，并用逐物体判定、中间快照和最终指标验证。

### 6.1 表面更新是同一状态下的几何推断

M1 对“旧状态是否结束”和“该旧表面是否仍有真实几何”查询不同边缘量：身份已搬走不意味着其后方的墙也消失。状态裁决限定合法观测域（R03–R06），TSDF 在该域估计当下几何，旧表面再根据同一测量和误差参数决定延拓。式 (9) 是已有等权截断残差均值；对固定合法贡献域，可写成对截断观测的平方损失最小化。截断、遮挡和状态域属于测量选择，不能因此宣称整个原始 RGB-D 似然已变成独立同分布高斯。

式 (10) 的直接票若采用对称二项测量模型，令 \(p>1/2\) 为一张有效票方向正确的概率，则“旧面应退出”对“旧面应保留”的对数似然比为 \((F-H)\log[p/(1-p)]\)；等先验、等局部错误损失产生现有多数规则，平票延续。这里不选新的 \(p\) 数值，它只说明多数规则的概率结构。带内遮挡的 \(2B_T>B\) 对应“近邻重复层”对“真实更深遮挡面”的同类比较。它只在 \(H=F=0\) 时生效：有直接测量时不能让由其派生的遮挡摘要重复投票。

式 (11) 对应同一表面在两次观测中的尺度错位解释：容差窗、到达视角、视线方向和近表面下界共同约束对应。\((s_A+s_B)q\) 是原实现取正尺度的保守误差窗，**不是**两个独立尺度噪声的方差相加，也不是严格的 \(|s_A-s_B|q\) 物理偏差。保留该机制处理旧拷贝躲在新表面后方的残影；概率推广应积分尺度/对应的不确定性，不能直接换成另一个较窄公式。式 (12) 的 64 方向是同身份新表面对旧点的内外解释，不是 64 次相机观测；在 M1 中应条件于已估计的新几何，不能把它们再当独立深度帧。

## 7. 终结、序列化与递归接续

在线变化检测在每个独立片段上完成；其后按物理 ID 归并逻辑实体。终结最后一次归并后重新处理新摄取片段并刷新射线索引，然后执行会话末表面更新，最终时间与最后 ACK 输入一致。

恢复版持久包包含：

| 文件 | 保存的内容 | 下一会话用途 |
|---|---|---|
| `final.4dmap.zpk` | 本 session 的时间线及更新后最终图 | 评估、查看、旧格式恢复入口 |
| `chain_state.4dmap.zpk` | 表面更新前的最终推理 DSG | 下一会话在线变化推理的 seed |
| `shown_state.4dmap.zpk` | 更新后最终表面的一份快照 | 下一会话表面更新中的旧记忆 |
| `depth_scales.txt` | 历次深度尺度 | 式 (11) 的历史误差窗 |
| `sensor_statistics.txt` | 缺失证据的总体统计 | 式 (7) 的校准 |
| `transition_manifest.json`、`state_summary.json`、`control/` | 数据、版本、配置、帧账、退出状态、地图摘要 | 追溯和验收 |

加载时优先读取 chain，旧格式直接读取 final；把最新推理 DSG 作为一个初始快照，随后追加本会话状态。已有各 session 完整历史留在各自地图文件中。运行时 registry 从当前 OBJECTS 重建；其闭合片段和未决候选目前保存在本进程运行状态中。当前包的恢复范围是已物化 current、地图时间线和上述统计。

当前恢复版直接使用原有 map 与 sidecar，`session_surface.bin` 未加入此状态协议。D3 通过加载与接入现有变化检测实现，下一会话按同一入口继续。

### 7.1 推理顺序、原生接入与持久化的逐项对应

工程契约决定 M1 看到了哪些数据、M2 恢复了哪些状态、M3 何时提交动作。它们是统一推断的实现条件；数组越界保护、文件完整性、消息 ACK、精确身份键不应改成概率。Khronos 原生算法及外部代码保持只读。

| 机制 | 模型位置与执行含义 |
|---|---|
| B01 | M1：先冻结一份证据快照，再在 Reconciler 改网格前验证所有 current/会话片段，防止索引与表面不对应。 |
| B02 | M1/M3：每个访问片段独立得到证据和存在区间后才按物理身份归并，避免合并先把不同位置证据混在一起；有 registry 时由其几何覆盖遗留 winner-takes-all。 |
| B03 | M3：最后片段摄入后再验证、终结、清背景、物化，只保存一个终态；补偿终局新位置来得晚而没参与判断。 |
| B04a | M1 的候选关联：粗背景体素对角线 \(\sqrt3v_{bg}\) 只找旧物体背景副本，覆盖独立网格 5–11cm 的差异，不授权删除。 |
| B04b | M1 的时间归属：背景点以自身时间、片段最后支持/确认的最大值界定查询，状态关闭后新建面受保护。 |
| B04c | M1 的几何边缘量：同位置任意身份实测都支持背景几何；最后几何支持之后的真实穿透才送入既有变化检测，前景遮挡中性。半背景体素加 1mm 是该表面的测距带。 |
| B05a | M1 的同状态对应：静态帧与最新帧在世界坐标双向比较，3×3 足迹、最多 512 样本，避免相机运动或连续小移动误当静态。 |
| B05b | M3 的片段分界硬近似：穿透至少 20 且占已判的比例大于 0.2，使用 5cm 带；保护部分视图，同时截掉真正不同位置的旧帧。来源 004c6b3，数值未有正式错误率推导。 |
| B05c | M1 的单次覆盖门：已判至少覆盖被采样面的半数才允许这一帧对分段；来源 282573a，避免图像边缘小片代表整物体。 |
| B06 | M1 的观测几何摘要：活动静态轨迹分块提交，绝对重建体素与轨迹长度脱钩；房间配置 0.02m，其他数据集用原配置（457442b）。 |
| B07 | M1 的两种表示：静态家具同时进入全局背景与 private mesh，动态内容被排除；B04c 补偿身份结束后背景副本仍在的情况（2f8847f）。 |
| B08 | M2 的两种状态表示：chain 保留推理 current，shown 保留展示表面；同一物理状态的推理摘要与表面估计分别接续，不在下一轮把整理几何误作原始观察（9c1a7c9→6b8e5c3）。 |
| B09 | M3 的提交范围：终态变化检测后只替换同戳的最终图副本，前序快照保留；失败保存已有地图（b8b299a）。 |
| RC01 | M2 的存在时间：物理身份无缺席证据时从首次直接观测起开放；有证据的中点是区间估计，另存传感器边界。registry 关闭与原生 presence 的已知边界须在验收核对。 |
| RC02 | M1/M3 的遗留对应近似：不相交包围盒只取较新 private mesh，重叠可积累；当前 registry 进一步按状态约束。不能无视调用路径同时改原生 Reconciler。 |
| RC03 | M1 的覆盖分母：真实覆盖但身份未决计入置信度分母，时间方向决定窗口；未决不等于没有覆盖或明确缺席。 |
| RC04 | M1：物理片段每轮对最新不可变证据重算，先各自检测再折叠；D3 是恢复状态之后执行同一 D2。 |
| RC05 | M3 的安全执行：背景索引与网格/changes 长度同时校验，防止擦除后的陈旧索引中止会话。 |
| I01 | M1 的条件输入：跨会话稳定物理 ID、语义/物体背景映射和人工目录已冻结；类别先验可以推广，不能通过改目录/播放器重标物体改变答案。 |
| U01 | 原生活动窗口、跟踪 D1、在线 TSDF、射线 D2、Reconciler 与 4D 存储提供测量处理、状态提案与执行基础；项目在固定接入点推理同一物理状态，未重新推导或改写原生算法。 |
| E01 | M2/M3 的无损编码：`.zpk` 每 10 快照关键帧和增量压缩保留时间线；反向查询保留首见等于查询时刻的顶点，序列化不增加衰减。 |
| E02 | M3 的保存完成条件：5 秒窗口、最多一分钟等待保存 ACK，失败有退出状态而不 abort；这些是运行超时，不是持久性先验。 |
| E03 | M1 的帧完整性：/tf 就绪及 DDS 1ms 初始心跳、10ms 心跳、1ms NACK 恢复，配合逐帧 ACK 防止掉帧；保持冻结播放协议。 |
| E04 | M3 的资源调度：队列排空后释放已消费缓冲/证据、保留帧档案供表面更新；释放内存不等于删除历史地图。 |

当前源码另外两处要与谱系一起记录：`static_surface_selection.cpp::preparePhysicalTrack` 在动态位移小于配置下限时将轨迹回退静态，属于 M1 的运动可信度硬切换（房间配置 1m，头文件默认 0.2m；实际使用冻结配置）；`physical_object_merge.cpp` 无 registry 的遗留几何选择使用重建支持量、动态历史及旧格式种子支持 1000，属于 M1 的摘要可信度近似。生产 SessionBackend 有 registry，不能把遗留路径的门槛当作当前物理状态的决策依据。
