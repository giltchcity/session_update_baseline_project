## 1. 系统目标与完整递推

D1 是持续可见的运动，D2 是同一运行内的隐藏变化，D3 是跨 session 空档的隐藏变化。会话输入 \(Y_k=\{(t_i,I_i,D_i,L_i,T_i)\}\) 包含时间、颜色、深度、物理身份及相机位姿；语义类别另行保存。持久状态为 \(P_k\)。保留现有执行顺序：

\[
P_k=\operatorname{Save}\!\left[\operatorname{Surface}\!\left(
\operatorname{Drain}[\operatorname{Fold}_{Y_k}(\operatorname{Khronos}+\operatorname{IdentityEvidence},
\operatorname{Load}(P_{k-1}))],Y_k\right)\right].\tag{1}
\]

`Drain` 只表示处理完已接受输入；`Surface` 由最终放置状态选择合法观测，更新当前表面；`Save` 保存下一次递推实际需要的状态。

| 首版核心职责 | 已有机制解决的问题 | 本稿选定的计算 |
|---|---|---|
| 观测解释与自校准 | 穿透、遮挡、暗面、反光、mask 不完整 | 冻结参数的波束混合似然；本会话重复观测在线估计正常残差与异常权重 |
| 放置状态判断 | 同身份换视角还是搬动、旋转后部分重合 | 当前表面证据快照上的局部贝叶斯比较；允许只一部分可靠表面失配；一个全局暂缓决策 |
| 状态条件下的几何更新 | 同状态补全、历史污染、背景副本和双层面 | 状态授权的加权 TSDF；背景按自身几何证据维护；同状态不重复追加估计面 |

P1–P13 是这些职责的原理编号，不是十三个软件模块。来源记录、缓存和保存恢复只承担最少的接续职责，不作为独立科研贡献。

**首版的近似边界。** 使用固定的局部几何估计、低维噪声参数和有限证据快照，不枚举全场景几何或全部历史路径。不新增 Gamma–Poisson 类别率、全几何最大熵先验、全局总变差求解器或 ICP 模块。类别采用场景表的软先验；无独立标定集也能冷启动。忽略的相关性、候选不足和几何近似在对应章节说明，不要求先证明精确后验误差再写代码。

研究仍比较
\[
Q_{\rm current}(A\to B)\ge Q_{\rm current}(B),\qquad
I_{\rm persistent}(A\to B)>I_{\rm persistent}(B),\qquad
\operatorname{Ghost}_{\rm current}(A\to B)\to0.\tag{2}
\]
这是目标而非定理。没有观测的变化不可凭空恢复；最终还须与有效旧版按相同输入和 GT 指标对比。阶段性退化用于定位问题，不是最终完成状态。

## 3. 身份、状态与时间

物理身份 \(\ell\) 跨会话稳定，但一个身份可有多个先后放置状态。物体只重建出一部分仍是有效输入；未建出的部分是未知，不等于空。背景是几何归属，未知标签是缺测，不能混用。

\[
S_{\ell,s}=(G_{\ell,s},b_{\ell,s},t^{\rm support}_{\ell,s},d_{\ell,s},\mathcal M_{\ell,s},\Theta_{\ell,s}),\quad
P=(\{S_{\ell,s}\},\{Q_\ell\},\Theta_g,w).\tag{3}
\]

\(G\) 是当前放置的局部 TSDF/网格，\(\mathcal M\) 是最新观测证据快照，\(\Theta\) 是校准统计，\(Q\) 保存尚不能归属的新片段，\(w\) 是输入处理位置。历史状态保存几何和时间区间，不继续接受当前状态的新测量。

一个静态放置要求其已知表面在共同世界坐标内相容；这就是首版使用的刚体不变假设。改变假设只表示旧放置失效，**不声称已经估计出唯一新位姿**。新放置几何从本会话真实片段建立；不把旧完整 mesh 强行搬到一个新包围盒。原生运动轨迹仍由 Khronos 提供。

已摄取来源集合记为 \(\mathcal U\)。类名只给持续性先验，物理 ID 用于观测关联；两者不同。身份延续、放置延续、某处仍有几何分别输出，不能合成一个 `changed` 标志。

### 3.1 片段的合并与关闭

**原理 P1：同一测量只形成一份信息。**

- **假设。** 采集来源键不可变；派生片段、重投影和网格保存其来源引用。给定场景和共同误差变量，测量按其真实联合分布生成。复制、回放及保存只是确定性变换。
- **推导。** 对已经观察到的 \(Y\) 及其确定性副本 \(f(Y)\)，有 \(p(X\mid Y,f(Y))=p(X\mid Y)\)。因此新信息集合为 \(\mathcal U^+=\mathcal U\cup\mathcal U_{\rm incoming}\)。只有差集进入新似然；新的一次真实拍摄具有新键，即使数值相同也计为新观测。
- **充分性。** 集合并幂等，确定性派生量条件于原数据后提供单位因子，故重复交付严格保持后验和风险不变。
- **必要性。** 设正确 GT 假说的先验优势为 \(O>1\)，一个偶发误测的似然比为 \(r<1\)，且 \(Or>1>Or^m\)。真实单次观测仍选 GT；将其复制 \(m\) 次并误当独立证据则改选错误几何。任意满足此不等式的 \(O,r,m\) 都构成反例。
- **近似。** 完整来源集合的去重是精确运算，误差为零。只凭空间距离识别来源会将独立重观测合并，或将同源偏移副本重复计数；空间距离与来源相等之间没有通用误差界。来源不全的旧地图只导入一次，以原生表示尺度初始化不确定性；首版不声称恢复其已丢失的来源关联。
- **文献。** [Thrun 的前向占据模型](https://robots.stanford.edu/papers/thrun.occ-journal.pdf)处理测量依赖；上面的幂等结论直接来自条件概率与确定性映射。
- **预测。** 固定查询物理时刻，同一 A 视频重复回放，后验不变；对静态 A 重新采集，测量相关性经共同噪声模型处理后可继续降低不确定性。

同状态片段的几何集合、包围盒和时间按来源并集表达：
\[
G_{f\oplus g}=G_f\cup G_g,\quad
B_{f\oplus g}=\operatorname{bbox}(G_f\cup G_g),\quad
b_{f\oplus g}=\min(b_f,b_g),\quad
s_{f\oplus g}=\max(s_f,s_g).
\tag{4}
\]
先转换到共同世界坐标，再表达于共同包围盒。帧计数等于不同采集帧键的数量。式 (4) 合并表达，概率更新仍使用测量因子。

真实采集以 `(recording, camera, frame, pixel)` 定位；提取片段保留其输入区间。保存状态键、几何版本及已处理位置即可，不引入文件内容校验。测量时间而非线程完成时间决定状态区间。


### 3.2 同一个关系判定与状态转移

**原理 P2：类别是有限强度的持续性先验，不是状态开关。**

- **假设。** 首版估计“当前比较域中的观测是否仍属于同一放置”，不估计每秒事件率。每个场景可以声明类别静止倾向 \(s(c)\in[0,1]\)，二值表的静态/可移动分别对应端点；表缺项取中性值。表必须先于效果评估确定，不能由变化 GT 反向填写。
- **推导。** 对同放置倾向 \(v\) 采用均匀 Beta 初始分布，把一个类别声明作为总量为一的软先验信息：
  \[
  a_c=1+s(c),\quad b_c=1+1-s(c),\quad
  q_c=1-\mathbb E[v]=\frac{b_c}{a_c+b_c}.\tag{5p}
  \]
  因而静态类的变化先验为 \(1/3\)，可移动类为 \(2/3\)，未知类为 \(1/2\)。这是选定的弱先验协议，不是由传感器推导出的客观变化频率。
- **充分性。** 各类 \(0<q_c<1\)，有限且充分的几何似然比均可推翻类别倾向。类别只进入式 (5) 的先验赔率，不决定候选资格、距离公差或是否执行检测。
- **必要性。** 用零概率排除某类改变时，有限证据不能恢复该类真实移动。反之，已知静止倾向在证据稀疏时有可解释作用，但其净收益仍需实现后测量，不能由本推导保证。
- **近似。** 每次从当前证据快照重算，只加入一次类别先验；不是每帧再加一份语义伪观测。首版没有按空档秒数衰减的物理生存率，因此不预测未观测空档内的搬动次数。
- **文献。** [POCD](https://arxiv.org/abs/2205.01202)以环境类别知识软参与几何变化更新；这里借用软先验原则，**不声称复现 POCD 的语义幂权重、初始化或全部更新式**。[Persistence Filter](https://david-m-rosen.github.io/publication/persistencefilter-icra/)的时间生存建模是可选扩展，不是本稿数据前提。
- **预测。** 椅子与柜子使用完全相同的几何检测路径；类别只改变证据不足时的倾向。重复读取同一类别表不会逐帧压倒反向证据。

**原理 P13：只比较实际可构造的局部解释。**

- **假设。** 原生提取器提供当前放置、待归属新片段及其来源；可见性查询能访问既有表面和已观察自由空间。首版不要求形状完备，也不为所有可能新形状分配概率。
- **推导。** 对旧放置建立 \(H_0\)：其已知表面仍有效、未知部分可补全；\(H_1\)：已知表面中存在超出正常误差的变化。式 (7) 用一个共享的变化比例变量边缘化局部失配；无需枚举新位姿。待归属片段另外检验其自身的几何一致性。
- **充分性。** \(H_0\) 不把未重建区域当空，故换视角本身不是变化证据。\(H_1\) 允许部分重合，故不要求半数表面异位。唯一物理来源的副本不增加候选权重。
- **必要性。** 只允许“全部相同/全部不同”的点独立模型，会让旋转后的重合座面压制靠背变化；把未知区域当空又会把静止物体的新一面误判为移动。
- **近似。** 这是对旧放置的相容性检验，不是完整的刚体配准模型；错误 mask、变形和重建错误也可能使旧放置不相容。只有实际新片段支持新位置时才建立新几何，无法归属的继续 pending。
- **文献。** [Khronos](https://arxiv.org/abs/2402.13817)的片段与协调分层、[Panoptic Multi-TSDFs](https://arxiv.org/abs/2109.10165)的子图表示；变化比例混合是本稿选定的统计近似，不归因于旧代码或上述论文的原式。
- **预测。** 移动但没有新位置观测时，可以关闭旧放置而不给出虚构的新 pose；新视角只扩展未知域时保持未决或同状态补全，不按几何不相交直接继任。

给定快照 \(\mathcal M\) 与轮开始冻结的校准量，状态概率统一为
\[
\widehat p_{\rm change}=\frac{q_c B(\mathcal M)}{1-q_c+q_cB(\mathcal M)},\qquad
B(\mathcal M)=\frac{m_1(\mathcal M)}{m_0(\mathcal M)}.\tag{5}
\]

每轮从快照重算，不把上轮已经含有同一快照的后验再次相乘。首版是有限记忆、条件化的近似贝叶斯更新，不是全历史精确滤波。旧观测用于自校准和几何先验，其原始帧不能又作为当前变化的新证据。背景及没有类别的几何查询使用中性 \(q=1/2\)。

### 3.3 交接的守恒与证据归属

**原理 P3：保留、结束、暂缓来自同一个风险。**

- **假设。** 错误确认“仍有效”和错误确认“已失效”都支付单位损失；信息不足时允许暂缓。首版统一采用暂缓损失 \(c_D=1/4\)，这是全局动作协议，不是实测误报率。
- **推导。** 设 \(p=\widehat p_{\rm change}\)，则
  \[
  R(\mathrm{keep})=p,\qquad R(\mathrm{end})=1-p,\qquad R(\mathrm{defer})=c_D.
  \tag{5e}
  \]
  取最小风险：\(p<c_D\) 确认相容，\(p>1-c_D\) 确认失效，其余暂缓；边界平票暂缓。
- **充分性。** 比较三项线性风险即得到决策区间。类别先验单独给出的 \(p\in[1/3,2/3]\) 全在暂缓区间，因而没有几何证据时，类别本身不能关闭状态。
- **必要性。** 不提供暂缓动作会把仅见新侧面、没有任何旧位置反证的观测强制解释为合并或继任；其一可能污染状态，另一项可能丢失互补几何。暂缓用存储和延迟交换较少的不可逆错误。
- **近似。** 对局部近似后验最优，不保证真实频率错误为四分之一，也不直接最优于 mesh F1。暂缓损失是可在实现后做敏感性比较的决策选择，而非几何定律。
- **文献。** [Chow 的最优错误—拒判权衡](https://doi.org/10.1109/TIT.1970.1054406)；本节已给出完整风险展开。[POCD](https://arxiv.org/abs/2205.01202)提供几何变化与地图维护分层参照。
- **预测。** 证据充分才合并或关闭，证据不足保留旧显示并标识未确认，原始新片段进入 pending；不会用“反证多于支持”再次拦截已完成的概率判断。

确认相容后，同状态几何按式 (9) 更新；确认失效后旧状态进入历史。新状态必须有本会话真实静态片段，不能由类别或空网格制造。pending 只保存未归属观测，不额外产生一套状态门槛。

\[
\mathcal F^+=\mathcal F_{\rm old}\cup\mathcal F_{\rm session,closed}\cup\operatorname{settle}(Q),\quad
I_{\ell,s}=[b_{\ell,s},d_{\ell,s}).\tag{5b}
\]

真实离开时间通常只知道位于最近支持与首次有效反证之间。保存这个区间；单时间接口取裁决时刻作为上界，不冒充实际运动时刻。物理身份仍可延续，旧放置却已结束；同位置由其他物体占据时，几何存在与旧身份结束并不矛盾。

## 4. 同一测量的几何含义与物理证据

**原理 P4：所有层使用同一个可计算的波束似然。**

- **假设。** 主要观测来自不透明表面首交；以正常回波、未建模前景和异常回波的混合近似真实传感器。不要求预先知道深度与分割器的完整联合误差分布。相机位姿由已有输入提供。
- **推导。** 射线原点 \(o\)、单位方向 \(d\)、径向深度 \(r\) 给出端点 \(o+rd\)。由查询几何渲染预测首交 \(\mu\)，定义
  \[
  f(r\mid\mu,\Theta)=w_H N_{[0,R]}(r;\mu,\sigma^2)
       +w_O U(r;0,\mu)+w_A U(r;0,R),\quad \sum_jw_j=1.\tag{6}
  \]
  \(N_{[0,R]}\) 为在实际量程归一化的高斯；\(U\) 为指定区间的均匀密度。无有效首交时不用零长度的前景区间，而改用共同未知端点因子。量化回波使用实际编码格 \(\mathcal B_k\)：
  \[
  \mathcal L_\kappa(G)=\int_{\mathcal B_k} f(r\mid\mu(G),\Theta)\,dr.\tag{6e}
  \]
  各项都是高斯 CDF 或区间长度，能够直接算。无预测表面但已知自由区间用量程内的未知端点分量；从未观测的几何域对比较双方使用相同因子。
- **充分性。** 混合权重非负且和为一，编码格概率构成合法分布。已知前景在两个解释中产生相同首交时，两边似然相同。旧面挡住实际远回波时，正常分量失配，使撤销旧面的解释获得相对优势。
- **必要性。** 不区分遮挡和穿透，就不能同时保住被人挡住的墙和删除已搬走的椅子。把所有大残差都当变化，又会把暗面、反光和深度边缘当物体运动。
- **近似。** 高斯、均匀前景及异常分量是工作模型，不是完整物理模拟。未建模前景只近似中性，透明、多径、严重定位误差可能误判。未知无效深度首版一律不给变化证据，不凭无效码宣称自由空间；这牺牲一部分信息以避免依赖不存在的漏检标定。
- **文献。** Thrun、Burgard、Fox，*Probabilistic Robotics*，波束传感器模型；[Thrun 前向占据模型](https://robots.stanford.edu/papers/thrun.occ-journal.pdf)；[POCD](https://arxiv.org/abs/2205.01202)的 Gaussian–Uniform 混合。均匀前景替代常见指数短回波分量是本稿的简化。
- **预测。** 有效深度的小偏差给连续证据，不设独立的厘米级“同一/不同”窗口；无效回波、未知空间不作负票；可靠远回波逐步反对旧面。

物体归属可靠性用本对象已观测像素的标签一致统计近似：\(\rho_x=(1+n_{\rm same})/(2+n_{\rm seen})\)。为避免不稳定 mask 主导状态检验，用
\[
\bar{\mathcal L}_\kappa=\rho_x\mathcal L_\kappa+(1-\rho_x)\mathcal U_\kappa.\tag{6r}
\]
\(\mathcal U\) 是双方共用的未知端点因子。\(\rho\) 是可计算的标签一致性权重，不冒充有 GT 标定的归属概率；稳定的系统性错标仍可能失效。背景几何检验不要求对象标签。没有独立标定时，首版不把单次“同深度但标签不同”直接用于关闭旧对象；可靠新身份片段与几何共同进入状态关系。

证据只读取实际时刻不晚于当前处理位置的输入。像素投影和射线索引是同一观测关系的查询方式，不是两份独立证据。

### 4.0 静态重建与状态裁决共用端点证据

**原理 P5：选帧与状态归属共用同一比较，不再另设静态比例阈值。**

- **假设。** 原生静态片段和物理 ID 提供候选；候选由过去输入构建，评分使用尚未用于拟合该候选的新观测。未知部分允许互补，已观察自由空间必须保存。
- **推导。** 用式 (6e)、(7) 比较一个片段延续当前放置的解释。确认相容则把该片段的源帧归到当前状态；确认不相容则结束旧放置并验证新片段；暂缓则保留源帧而不混入已确认几何。
  \[
  \mathcal D_{\ell,s}=\{\kappa:\kappa\text{ 已归属到放置 }(\ell,s)\}.\tag{6b}
  \]
- **充分性。** 合并只影响同一状态的观测域；跨状态帧不会被一个静态 TSDF 平均。完全不同但相容的视角没有人为距离反证。
- **必要性。** 物体移动前后的深度若强制融合，会产生双影或中间表面；将静止物体正反面仅因不重叠而分开，则丢失有效补全。
- **近似。** 首版保留原生分段候选，项目只解决其相容性和归属；不能修复所有原生误跟踪。新候选来自本轮数据时，最早用之后的观测验证；这带来延迟，避免用拟合数据冒充独立检验。
- **文献。** [Khronos](https://arxiv.org/abs/2402.13817)的局部片段；[BOCPD](https://arxiv.org/abs/0710.3742)的预测比较。首版采用有限候选和快照，不实现完整 BOCPD 路径树。
- **预测。** 静态提取不再独立使用“覆盖过半、至少若干票、穿透率过界”的第二套裁决；同一新片段在选帧与状态层得到一致的归属。

原生运动输出 \(M_{\rm input}=\operatorname{KhronosMotionOutput}(Y_{\le t})\) 保留，作为运动片段与轨迹候选。它来自同一 RGB-D，不再与其原始射线作为两份独立似然相乘。首版不新增 ICP；局部旋转是否被检测取决于实际露出的几何反证，而不是保证某个角度必检出。

### 4.1 状态缺失是有限表面上的预测比较

**原理 P6：检验超出自身常态的局部失配，而不是要求多数表面失配。**

- **假设。** 正常放置的预测使用轮开始冻结的波束模型。变化后仍可有大量表面重合；给定变化比例 \(z\)，不同有效空间样本暂按条件独立近似。\(z\sim\operatorname{Beta}(1,1)\) 是本稿明确选择的无方向比例先验，不是每帧变化率。
- **推导。** 每个实际来源给出正常解释 \(f_{0j}\) 与替代解释 \(g_j\)。替代解释优先渲染已有的新片段或撤销旧面后的已知背景；没有可用替代几何时，只用量程内的未知端点分量。定义
  \[
  m_0=\prod_jf_{0j},\qquad
  m_1=\int_0^1\prod_j[(1-z)f_{0j}+zg_j]\,dz,\qquad
  B=\int_0^1\prod_j[1-z+z(g_j/f_{0j})]\,dz.\tag{7}
  \]
  这是一个一维积分，不是全几何后验积分；在对数域用现有数值库自适应求积。所有概率均用同一编码格和校准参数，未知来源满足 \(g_j=f_{0j}\)，不改变积分。
- **充分性。** 混合允许未变化样本继续服从 \(f_0\)，而显著失配样本由 \(g\) 解释。因而一部分可靠反证就可能令 \(B\) 很大，判决不等价于计数过半。正常误穿透已经进入 \(f_0\)，不再另外设置固定的在位比例上限。
- **必要性。** 椅子转动后座面重合而靠背被看穿；过半门会屏蔽局部明确变化。反之，只有全体替代的简单备择会过度惩罚重合部分。共享 \(z\) 正是为这两种解释之间提供连续的局部变化模型。
- **近似。** 条件独立、冻结校准和候选几何都是近似；空间相关会使后验过于自信。首版只保留每个地图采样单元的最新有效来源，同一像素至多贡献一次；共同尺度偏差先由 P8 处理，仍不宣称消除了全部相关性。最新来源会替换旧支持，所以长期静止票数不会无限锁死后来变化；代价是不保留全部时间信息。
- **文献。** [POCD](https://arxiv.org/abs/2205.01202)的内点/外点混合、[BOCPD](https://arxiv.org/abs/0710.3742)的后验预测思想。式 (7) 是本稿对局部部分变化的具体近似，不是旧 CUSUM 的等价改名。
- **预测。** 部分重合仍可检出；变化全部位于未观测域时无法判定；极少点、强相关伪影和错误候选会降低可靠性。并不承诺更多同视角帧必然识别任意小移动。

**本会话自校准与冷启动。** 不依赖另外采集的时序集或已知参考物体。复用原生静态片段中的重复观测：在冻结的旧几何上先预测，再更新几何和校准，不能先用本帧拟合再给本帧计算“预测分数”。确认相容的观测为下一轮提供正常参考；这是一种带选择偏差风险的在线自校准，不称作 GT 标定。

对式 (6) 的分量 \(a\in\{H,O,A\}\)，责任度及累积量为
\[
\gamma_{ja}=\frac{w_a f_a(r_j)}{\sum_bw_bf_b(r_j)},\quad
n_{\ell a}^+=n_{\ell a}+\gamma_{ja},\quad
w_{\ell a}=\frac{g_a+n_{\ell a}}{1+\sum_bn_{\ell b}}.\tag{7u}
\]
\(g\) 是除当前对象外的总体平均分量权重，和为一；总体为空时取对称值。这里总体只提供总量为一的弱收缩，局部观测只累计一次，不将同一对象再通过总体重复计入。无局部时使用总体；两者都空时使用对称混合与 P8 的表示尺度初值。正常分量的残差平方和、各视图残差均值及其方差同时保存，用于估计距离噪声和视图间波动。

参考：[Cappé–Moulines 在线 EM](https://arxiv.org/abs/0712.4273)。式 (7u) 是冻结责任度的简化递推，不引用其独立同分布条件下的收敛结论来保证这里的真实视频。高反光对象和静态片段误含移动可能污染校准；先记录失效，再在实际运行后修正，不为此添加另一套类别或票数开关。

## 5. 状态授权的会话末观测域

**原理 P7：同状态几何做条件估计，跨状态数据不混合。**

- **假设。** 固定当前放置与对应关系后，局部表面近似平面，正常有向距离误差近似高斯。历史 TSDF 已包含此前数据，新积分只消费新增来源。
- **推导。** 用 \(\mathcal D_{\ell,s}\) 授权测量；对体素距离 \(F\)，旧均值 \(F_0\)、精度 \(W_0\) 和正常距离测量 \(\phi_j\)，定义
  \[
  J(F)=\tfrac12W_0(F-F_0)^2+\tfrac12\sum_jw_j(\phi_j-F)^2,
  \quad w_j=\gamma_{jH}\rho_j/\sigma_j^2,
  \quad W^+=W_0+\sum_jw_j,\quad
  F^+=\frac{W_0F_0+\sum_jw_j\phi_j}{W^+}.\tag{9}
  \]
  已确认状态内 \(\rho\) 为对应/归属权重；背景几何不要求对象标签。分数权重对应冻结责任度的一步 EM 条件更新，不是重复增加一份独立传感器信息。
- **充分性。** \(W^+>0\) 时目标严格凸，求导给出唯一条件极小值。状态出生前的自由空间不进入新状态；历史与当前若是同一表面的两份估计，只更新一个距离场。
- **必要性。** 混用移动前后帧会产生折中面；把物体出现前的自由空间积分到其新放置，会挖空真实物体。完全丢弃同状态历史则损失未重观测部分。
- **近似。** 首版使用对角精度，位姿与尺度的不确定性折入 \(\sigma_j^2\)，不维护全体素协方差。平面近似误差局部为 \(O(\kappa r_{\rm patch}^2)\)；边缘、薄层、多峰对应和共享误差会使该近似失效。原生 TSDF 的截断和分辨率保留为表示参数，不再变成状态门槛。
- **文献。** [Curless–Levoy](https://graphics.stanford.edu/papers/volrange/paper_1_level/paper.html)的加权距离场，[Panoptic Multi-TSDFs](https://arxiv.org/abs/2109.10165)的子图和归属分层。
- **预测。** 相容多视角补全同一状态；退出状态留在历史，不形成当前双影；相关帧仍可能导致置信度偏高，这由后续真实残差检查，而非不存在的全局协方差保证。

保持原生 TSDF 的射线积分域；当前表面之后未观测的空间不能作为自由空间。会话末只用最终已归属状态的帧形成本次估计。未归属源帧保留但不强行混入当前状态，历史空白也不跨越放置边界。

### 5.1 测距校准的目标与数值协议

**原理 P8：优先用已有重复观测估计尺度和误差，没有数据也有明确起点。**

- **假设。** 输入位姿具有项目使用的共同尺度；相容静态区域可提供跨视角对应。首版估计一个会话尺度修正和局部残差统计，不估计完整传感器联合分布。
- **推导。** 对同一点的双视角对应使用
  \[
  e_j(s_d)=(1+s_d)r_{b,j}-\|o_{a,j}-o_{b,j}+(1+s_d)r_{a,j}d_{a,j}\|,\quad
  \widehat s_d=\arg\min_{s_d>-1}\sum_j\gamma_{jH}e_j(s_d)^2.\tag{9b}
  \]
  以正尺度的对数参数做一维加权最小二乘；求出的尺度用于修正测距，而不只是放大匹配窗。距离方差采用正常残差平方和、视图间残差方差、尺度估计方差和原生空间表示误差之和。
- **充分性。** 共同世界点等式产生上述残差；局部线性化给出尺度信息 \(\sum_j\gamma_{jH}(\partial e_j/\partial s_d)^2\)。有足够平移基线且该方向可辨识时可更新尺度；不可辨识方向不因样本多就获得精度。
- **必要性。** 将共同尺度偏差全当作场景变化会制造双层面；相反，将真实移动混入尺度拟合可能抹掉变化，所以仅使用已确认相容、且与当前待判片段分开的参考对应。
- **近似。** 自标定依赖静态参考选择与局部线性化。纯旋转、单一退化平面布局或整个场景同时移动可能不能可靠估尺度；此时沿用已有尺度，无已有尺度取单位尺度，不冒充已完成标定。
- **文献。** [Nguyen–Izadi–Lovell](https://users.cecs.anu.edu.au/~nguyen/papers/conferences/Nguyen2012-ModelingKinectSensorNoise.pdf)讨论深度噪声；本项目的尺度目标来自双视角点几何，在线参考选择是明确的实现近似。
- **预测。** 共享尺度误差应在多个相容区域呈共同趋势；局部物体变化不应靠全局尺度吸收。纯旋转下不承诺跨会话窗口自动缩小到某个厘米值。

**无标定冷启动。** 设原生截断半带为 \(T\)，体素边长为 \(h\)，编码格宽为 \(u\)。取单位尺度、对称混合权重、
\[
\sigma_{\rm boot}^2=T^2/3+(h^2+u^2)/12.\tag{9c}
\]
这是将截断带内和编码/网格内位置作均匀表示的启动近似，不声称它是真实设备噪声的上界。已有正常残差后，用总量为一的初始平方残差 \(T^2/3\) 与新平方和更新正常方差，并保留量化/表示项及视图波动；不足时保留启动不确定性，不用零残差假装高精度。没有可辨识尺度参考时不运行另一套标定算法，也不读取评价 GT。

**首版参数表。** 第一类为实际输入/观测量，第二类为明确计算结果，第三类为公开的建模、决策及计算协议；第三类不冒充传感器定律。场景类别表是用户允许的环境先验输入。

| 量 | 类别 | 取得方法及唯一含义 |
|---|---|---|
| 内参、位姿、有效量程 \(R\)、深度编码 \(u\)、时间、物理 ID | 第一类 | 已有输入；未知误差不填写虚构标定结果 |
| \(h,T\)、原生选帧/采样预算 | 第一类输入的原生表示合同 | 从现有配置读取；继续用作表示和工作量预算，不解释为继任/删面阈值 |

## 6. 一个表面解释、一个保留判定

**原理 P9：同状态融合一个估计，不把估计副本追加成新表面。**

- **假设。** 历史 TSDF/mesh 与本次 TSDF 是具有来源和放置状态的几何估计；同一局部分支可由一个有向距离场表达。
- **推导。** 同状态已覆盖区域由式 (9) 更新，并从更新后的距离场提面；未重观测区域保留历史估计。在线补全面只在本次最终融合尚无估计、且有独立当前源观测时作为候选，再用 P3/P4 的同一局部检验确认。
- **充分性。** 同状态同分支不同时追加旧、新两份独立估计，因此不由存储方式制造双层。没有当前源观测的历史副本不能以“新补全面”身份重新进入。
- **必要性。** 有误差的旧、新平面分别追加会制造两层，即使二者都曾得到支持。相反，直接删光历史会失去本会话没有重观测的真实部分。
- **近似。** 一个距离场的边界唯一，**不代表真实场景没有两层**。真实薄板、未建模前景和错误对应仍可能产生双层或误融合；首版不以“在里面”、空槽或最近距离单独删面。分辨率不足的结构列为已知限制。
- **文献。** [Curless–Levoy](https://graphics.stanford.edu/papers/volrange/paper_1_level/paper.html)、[Panoptic Multi-TSDFs](https://arxiv.org/abs/2109.10165)。
- **预测。** 同一面反复存储不提高存在置信度；真实新视角能补全；纯遮挡后方的历史面没有独立删除依据。

漏进背景的物体 mesh 由背景自身的几何检验维护。旧放置结束只用于定位应重查的背景区域，不能直接删除相邻背景。射线穿透才提供其不再存在的证据；同位置仍有表面则可以继续保留几何。对象与背景使用同一深度测量，但不能把两个模块的后验再作为独立证据相乘。

### 6.1 测量与重测的对应关系

**原理 P10：相同表面的重新估计与真实新结构，比较可见预测。**

- **假设。** 比较域来自此前已经看到的表面及自由空间，而不是旧 mesh 的外包围盒。新候选必须有真实来源；拟合候选与评分来源分开。
- **推导。** 旧面查询使用旧放置的预测首交；新片段落入此前实测自由空间时，调用保存的旧射线预测作反向比较。每个实际像素只保留一份首交比较。
  \[
  b_j=g_j/f_{0j},\qquad
  \log\frac{N(r;\mu_1,\sigma^2)}{N(r;\mu_0,\sigma^2)}
  =-\frac{(r-\mu_1)^2-(r-\mu_0)^2}{2\sigma^2}.\tag{12}
  \]
  有限量程内还加各自截断归一化项，完整评分使用式 (6e)、(7)。共享尺度修正先作用于双方，不能只给某个解释扩大窗口。
- **充分性。** 相同首交产生相同证据；有效远回波反对挡在前面的旧面。仅仅与旧 mesh 距离远，但空间此前未知，不构成失配。
- **必要性。** 不保存已观察自由空间，就无法区分“新看到椅背”与“椅背进入原来确定空着的位置”。只凭最近距离合并，则可能抹掉真实薄双层。
- **近似。** 局部对应由现有投影与网格索引提供，未估计完整对应后验；错误对应会误判。已知前景在双方相同时中性；未知前景由短回波分量近似，不能保证所有遮挡严格相消。
- **文献。** [Thrun 前向占据模型](https://robots.stanford.edu/papers/thrun.occ-journal.pdf)、[POCD](https://arxiv.org/abs/2205.01202)的几何比较。
- **预测。** 部分重叠旋转只在露出的可靠变化处产生反证；新旧两处都没看到时保持未决。只见另一面不自动等于配准失败或移动，也不虚构旋转角。

### 6.2 从解释损失导出保留式

**原理 P11：实现只计算有限状态和局部积分，不等待不可计算的全局误差界。**

- **假设。** 当前几何与低维校准参数作插件估计；每个可靠空间单元保存最新可用观测，保留 pending 片段但不展开历史路径的笛卡尔积。
- **推导。** 每轮固定快照，计算式 (7) 的一维积分，再以式 (5)、(5e) 得到动作；确认相容才更新该放置 TSDF，失效才结束旧状态，其余保留未决。积分的数值误差仅针对当前固定快照的积分值。
- **充分性。** 有限样本上的正连续混合可以用常规数值积分计算；局部条件高斯更新只需均值、精度与累积和。每一步都有明确的输入与有限存储，不以精确全场景后验作为运行依赖。
- **必要性。** 只写“对所有几何/关联积分”而不给表示，无法规定代码该存什么；要求测量与未知精确后验的总变差也不能实现。反过来，省去正常误差、时间归属或来源，会产生前述具体反例。
- **近似。** 快照丢失早期观测，插件估计丢失参数后验尾部，条件独立忽略相关性，候选与 TSDF 丢失部分形状。没有全局 \(2\delta+\eta\) 保证。之后只对这些可定位近似做更密采样、不同精度和误差场景比较，不先搭建另一个精确求解器。
- **文献。** [POCD](https://arxiv.org/abs/2205.01202)的有限参数近似与 [Khronos](https://arxiv.org/abs/2402.13817)的分层计算；本节明确选择的快照/插件近似不归因于论文的全局正确性结论。
- **预测。** 空间上持续出现的可靠反证能更新状态；只有相关伪影或无新可观测区域时可能保持未决或发生误判，需在实现后定位，不提前宣布不会失败。

**一轮实际计算顺序。**

| 次序 | 读取 | 计算 | 写回 |
|---|---|---|---|
| 输入 | 新 RGB-D、标签、位姿、原生片段 | 过滤已处理采集来源，读取旧地图的已知/空闲/未知域 | 新源观测和待归属片段 |
| 冻结 | 旧几何与上一轮校准统计 | 固定预测参数与候选；不使用本帧先拟合后打分 | 本轮预测快照 |
| 证据 | 当前视锥内采样、保存的自由空间 | 首交编码格概率；每格最新来源；同像素去重 | 更新 \(\mathcal M\) |
| 状态 | \(\mathcal M,q_c\) | 一维积分 \(B\)，计算变化概率与三动作风险 | refine / end / pending、状态时间区间 |
| 几何 | 已确认归属的新源观测 | 式 (9) 的 TSDF 更新；背景同类局部检验 | 当前子图、历史、背景 |
| 学习 | 本轮已确认相容的重复观测 | 责任度、正常残差、标签一致统计、可辨识尺度 | 下一轮使用的 \(\Theta\) |
| 会话末 | 归属与几何、未决数据 | 按最终状态授权重融合并提面 | 可续接状态与显示地图 |

空间采样和图像访问先复用项目现有预算与索引，避免每轮全量射线扫描。以 \(N\) 个活动采样、\(K_q\) 次积分节点计算计，变化比较主要为 \(O(NK_q)\)，证据存储为 \(O(N)\)；TSDF 工作量取决于受新射线影响的体素。pending 内存仍可能增长，首版沿用既有片段容器，不声称固定总内存。

数值积分失败或非有限数时，本轮暂缓并记录原因，不把它解释为物体消失。不做文件哈希或逐字节对照；保留输入能否解析、索引是否合法等运行必需条件。

### 7.1 活跃查询的充分状态

**原理 P12：保存的是已选近似算法需要的状态，不是完整后验。**

- **假设。** 下一轮只读取当前子图、校准统计、证据快照、状态时间、pending 片段和新的输入。
- **推导。** 保存
  \[
  P_E=(\{G_s,F_s,W_s,b_s,t_s^{\rm support},d_s\},\{\mathcal M_s\},
       \{n_{sa},\text{残差统计、标签统计}\},s_d,\operatorname{Var}(s_d),
       \{Q_\ell\},w,\text{来源引用}).\tag{15b}
  \]
  恢复这些量后继续 §6.2 同一个更新，不保存一般概率密度、所有历史路径或全局体素协方差。
- **充分性。** 在首版更新定义及相同数值顺序下，所需参数均已保存，因此进程边界不改变其数学递推。这里说的是状态语义，不要求文件的二进制排列一致。
- **必要性。** 只存网格会丢掉正常误差、待归属帧和最近反证，下一会话可能重新把同一测量计一次，或无法继续判断旧放置。
- **近似。** 与完整历史的精确后验并不等价。旧格式缺少字段时仅从其真实保存的信息初始化；不能补造过去的概率或来源。恢复后的数值差异不由文件摘要判定。
- **文献。** [Persistence Filter](https://david-m-rosen.github.io/publication/persistencefilter-icra/)的递推思想；本节充分性仅针对本文已选定的有限状态更新。
- **预测。** 重启后保留未决观测与已学噪声，而不是只剩一个没有置信度的 mesh；旧格式导入可继续运行，但不能保证复原丢失的信息。

### 7.2 同一历史查询与完整发布

历史查询仍采用不晚于请求时刻的已发布快照：
\[
j(t)=\max\{j:t_j\le t\},\qquad Q(t)=G_{j(t)}.\tag{16}
\]
第一份快照以前返回未知/空的已知域。显示地图与可续接状态分开：前者给用户看，后者还保存 pending 和统计量。保存频率不应重置校准或增加观测。仅保留既有成功/失败反馈，不额外创建文件内容校验流程。

SPRT 的边界推导以归一化简单假设似然比为前提；Wald 名义界及过冲影响参见 [Fischer–Ramdas](https://arxiv.org/html/2410.16076v1)。CUSUM 的原始来源为 [Page，Continuous Inspection Schemes](https://doi.org/10.1093/biomet/41.1-2.100)。对未知变点的 \(K\) 个对数权重 \(v_k\)，有
\[
\max_k v_k\le\log\sum_k e^{v_k}\le\max_kv_k+\log K .
\]
这说明“取最强变点”与“对变点后验求和”是不同近似；重置分支本身并不自动证明错误，也不自动与贝叶斯模型等价。
