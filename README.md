## 1. 系统目标与完整递推

D1 是持续可见的运动，D2 是同一运行内的隐藏变化，D3 是跨 session 空档的隐藏变化。每个 session 启动新进程和短期跟踪器，恢复前序地图后继续执行完整 D1/D2。

设会话输入为 \(Y_k=\{(t_i,I_i,D_i,L_i,T_i)\}_{i=1}^{n_k}\)，分别包含时间、颜色、深度、物理身份和相机位姿；语义类别另行保存。持久状态为 \(P_k\)。完整算法的组合为

\[
\boxed{
P_k=\operatorname{Save}\!\left[
\operatorname{Surface}\!\left(
\operatorname{Drain}\!\left[
\operatorname{Fold}_{Y_k}(\operatorname{Khronos}+\operatorname{IdentityEvidence},
                         \operatorname{Load}(P_{k-1}))
\right],Y_k\right)\right].
\tag{1}
\]

式中 `Khronos + IdentityEvidence` 表示已有在线执行链在确定的回调点组合项目扩展。`Drain` 排空处理队列、异步变化检测和最后到达的物体片段；`Surface` 用最终状态限定观测，再更新会话末表面；`Save` 提交下一进程读取的状态。

初值 \(P_0=\varnothing\)，同一运行入口完成 \(P_0\to P_A\to P_B\to P_C\)。下一会话读紧邻前序状态；旧 session 的完整输入视频和整条快照序列留在原产物中。

研究验收同时衡量三个目标：

\[
Q_{\rm current}(A\to B)\ge Q_{\rm current}(B),\quad
I_{\rm persistent}(A\to B)>I_{\rm persistent}(B),\quad
\operatorname{Ghost}_{\rm current}(A\to B)=0.
\tag{2}
\]

这是评价目标。准确度按真实 RGB-D/GT 检查，信息增益来自未重观测区域的保留、静态多视角补全和时间历史。移动物体旧状态进入 HISTORY，新位置进入 CURRENT；全过程和最终时刻分别检查。

### 1.1 一个测量模型、一个持续性先验、一个决策准则

统一的状态是物理身份的分段几何、存在区间和表面来源，记为 \(X_t\)；\(\Theta\) 是深度误差、标签漏检和样本可靠性的测量参数。当前状态有三个竞争解释：旧状态延续且补充另一视角 \(H_S\)、同一身份已经换状态 \(H_M\)、旧状态消失且暂未重建继任者 \(H_A\)。`observed_new` 和 `b_session` 保存尚不能排除的解释及其观测几何。背景表面是否仍在，是同一 \(X_t\) 的几何边缘问题。

**测量似然。** 全部推理以同一批有时间和来源的实际 RGB-D 测量为条件：

\[
\mathcal L_t(X_t)=p(Y_t\mid X_t,Y_{<t})
=\sum_{a,v,z}\int p(Y_t,a,v,z\mid X_t,\Theta)\,
 p(\Theta\mid Y_{<t})\,d\Theta . \tag{M1}
\]

\(a\) 是测量与状态/表面的对应，\(v\) 是可见、遮挡、未覆盖等观测条件，\(z\) 是表面样本是否可靠。深度、身份和可见性共享同一次测量；几何重叠、射线计数和缺席比例都是它的摘要。计算联合似然时须保留这种依赖，不能把同一像素的几个摘要相乘当作独立证据。相机模型给出式 (6) 的残差；身份混淆条件于深度和关联；颜色供外观与属性重建。无测量时似然比为 1；有前景遮挡时，积分掉被遮挡表面的未知状态，不能投旧物体缺席票。

当前代码对 M1 使用三种已有计算：实测端点分类和足迹计数、可靠表面上的 Beta 缺席统计、状态授权观测域内的 TSDF/表面对应。它们服务不同粒度的状态量，误差尺度由量化、层分辨率及已有传感器统计给出。统一要求它们使用相同测量来源和状态时间，保留各自处理的误差；用同一个固定距离替换这些尺度会丢失现有机制。布尔可靠性、硬对应、硬噪声窗是 M1 中尚待概率化的部分。

M1 的深度项可具体写为同一首回波模型。令 \(\rho_a(X)\) 为射线与假设表面 \(a\) 的距离，\(F_q\) 为该量程下测距残差的分布函数，\(h\) 为表面离散半尺度；均匀单元不确定性与测距误差的卷积密度为

\[
g_{q,h}(e)=\frac{F_q(e+h)-F_q(e-h)}{2h},\qquad
p(r,\widehat\ell\mid X,\Theta)
=\sum_a\pi_a(X)\,g_{q,h}\!\left(r-\frac{\rho_a(X)}{1+s}\right)
 Q(\widehat\ell\mid\ell_a,r,a). \tag{M1a}
\]

\(\pi_a\) 包含足迹内的对应与首回波可见性，\(Q\) 表示已关联端点的身份识别/漏标；无效读数由两假设共享的缺测分支处理。遮挡由更近表面生成回波，旧表面后方没有被测到的部分不产生空位票。现有深度直方图和尺度估计给出 \(F_q,s\) 的信息；现有硬命中带、足迹全称判断和 \(\tau\) 是这个卷积/关联计算的近似。M1a 是推广定义，当前实现仅保存部分统计（例如绝对残差而非完整有符号分布），后续条目须说明怎样由已有测量识别所需量。

对一个在位物体的可靠表面，设 \(n\) 个已判单元里有 \(k\) 个被看穿；将上述误差、漏测和局部形状误差压缩为在位穿透率 \(f\sim\mathrm{Beta}(\alpha,\beta)\)，可得

\[
p(k\mid n,H_S)=\binom nk\frac{B(k+\alpha,n-k+\beta)}{B(\alpha,\beta)},
\qquad p(k\mid n,H_A)=\frac{1}{n+1}. \tag{M1b}
\]

后一项来自原有 absent 均匀比例模型。当前代码直接用连续比例 \(k/n\) 的 Beta 密度近似并作单侧处理，得到式 (7)；M1b 说明有限覆盖数的不确定性放在哪里，不授权替换已经工作的 CUSUM。表面方向投票、像素覆盖及对应概率也应条件于同一观测和几何，不能重新增加独立相机证据。

**持续性先验。** 对身份 \(\ell\)，令 \(q_\ell\) 为相邻有效观察之间换状态的概率，\(K_\ell\) 为发生变化后的状态分布：

\[
p(X_{\ell,t}\mid X_{\ell,t-1},q_\ell)
=(1-q_\ell)\,\delta_{X_{\ell,t-1}}(X_{\ell,t})
+q_\ell K_\ell(X_{\ell,t}\mid X_{\ell,t-1}). \tag{M2}
\]

这里的延续指状态与历史归属延续，允许新测量补全该状态的几何。\(K_\ell\) 只能接收新状态自身的实际观测，不能把旧形状搬到新位置。一身份同一时刻至多一个 CURRENT、历史不可并入另一状态、未来测量不可支持过去，构成 M2 的合法状态空间。无有效观测时不推进一次变化试验；现有代码没有连续时间危险率，不能把 backend 回调次数当成物理变化次数。

`isHighMobility` 的类别表、D1 历史和已关闭片段都在近似 \(q_\ell\)，不是额外的删除证据。其概率推广为同一层次先验：类别提供 \(q_\ell\sim\mathrm{Beta}(a_c,b_c)\)，该物体有效状态机会中的变化/延续证据 \(m_\ell,u_\ell\) 更新为 \(\mathrm{Beta}(a_c+m_\ell,b_c+u_\ell)\)。类别只影响先验；后验决策不再查类别表。\(a_c,b_c\) 和有效机会的定义尚未由现有实现校准，本说明不填造数值，也不把同一次 D1/关闭事件重复用于当前似然和当前先验。现有 `sensor_statistics.txt` 校准 M1 的测量分布；它不是 \(q_\ell\) 的运动频率。

类别名单给出历史汇总组及一条可动/持续的先验意见，避免只分组却丢掉类别方向。令 c 为类别在可移动表内的指示，o 在配置了非空类别表时为 1，未配置时为 0。计算目标物体时排除它自己的全部历史：同类其他物体给出 \((m_c,u_c)\)，同组其他类别给出 \((m_g,u_g)\)。以 Bernoulli 的 Jeffreys 参考先验 \(\mathrm{Beta}(1/2,1/2)\) 处理无历史情况；类别意见的先验信息因子为 \(q^{oc}(1-q)^{o(1-c)}\)，每条意见只计一次，既不当作 GT 运动观测，也不重复加入物体历史。组先验总质量 \(\kappa=1+o\) 传给类别层：

\[
\mu_g=\frac{m_g+1/2+oc}{m_g+u_g+1+o},\quad
 a_c=\kappa\mu_g+m_c,\quad b_c=\kappa(1-\mu_g)+u_c,\quad
 q_\ell=\frac{a_c+m_\ell}{a_c+b_c+m_\ell+u_\ell}.\tag{M2a}
\]

**P02 已保留：共享体素支持的量化概率。** S03 保留“至少一个共同表面支持同状态、无共同支持只暂存”的语义。把每张网格按现有分辨率 \(r\) 分组，每个非空体素只取其实际顶点的均值作为关联代表；这些代表只用于本门的统计，不改几何、输入帧或评分采样。给定当前位姿，一个对应点对的公共体素相位在一格内均匀分布，则两点 \(x,y\) 共格的概率为

\[
p_{xy}=\prod_{j=1}^{3}\left(1-\frac{|x_j-y_j|}{r}\right)_+,
\quad p_v=\max_{w\in\mathcal N(v)}p_{x_vy_w},\quad
p_{\cap}=1-\prod_v(1-p_v). \tag{M1c}
\]

正部来自共格事件本身的有限支撑，并非额外距离截断；邻域只需原格及相邻格，因为更远代表的共格概率为零。\(p_v\) 保留原机制的最佳对应选择，跨候选体素的量化误差在给定位姿后采用独立近似；它不把同格的三角顶点当独立相机证据。M1c 是 M1 关联分支的局部近似：用 \((p_{\cap},1-p_{\cap})\) 作为共享支持/未获共享支持的软证据因子，不能把它说成已标定的整物体搬动似然。与 M2a 相乘后，M3 的对称关联风险给出 \((1-q_\ell)p_{\cap}>q_\ell(1-p_{\cap})\)。平票和证据不足进入原有候选槽；通过此门仍须通过原 `observedEmptySince` 保护。网格分组、半格相位范围及公式有限支撑全部由既有 \(r\) 决定，没有新增数值参数。计算可在累积概率的下界已超过 \(q_\ell\) 时结束，因为后续因子只会增加共享概率；诊断明确记录该下界。该关联近似是否可保留，仍以原测试、逐物体动作及固定 GT 验证，不以公式外观判断。

\[
w_j(\delta)=\frac1h\int_{-h/2}^{h/2}{\bf1}\{\delta+u\in R_j\}\,du,\qquad \sum_jw_j=1. \tag{M1m}
\]

同身份表面的区域为 [−T,T]，更近为遮挡、更远为穿透；其他身份或背景仍在 δ<−min(T,h) 时属于遮挡，不能借宽匹配带给前景后方投替代票。中间区间按原身份类型区分背景、他物和未识别，未识别保持中性；无效与不可用读数各为自己的单位质量。CDF 的 0/1 边界来自有限量化区间；h/2 来自四舍五入，没有新截断、误报率或平滑宽度。M3 的等分类错误损失选择最大关系质量；平票仍选择闭匹配区间的表面关系。固定运行配置的匹配带宽大于量化格，因此非边界的最大质量分类与原分类相同，但边界附近的不确定性已可通过项目接口读取，例如原 P12 反例返回约 3/4 支持、1/4 穿透。

**决策准则。** 所有动作使用一个约束后验风险最小化问题：

\[
\pi_t(X)\propto\mathcal L_t(X)\int p(X\mid X',q)\pi_{t-1}(X',q)\,dX'\,dq,
\qquad a_t^*=\arg\min_{a\in\mathcal A(X)}\mathbb E_{\pi_t}[C(a,X)]. \tag{M3}
\]

\(\mathcal A\) 包含保持、合并同状态、关闭/接任、暂存候选及表面更新。损失 \(C\) 区分误关真实物体、遗留旧位置、合并不同状态和丢失真实表面；来源、时序和物理身份约束限定可执行动作。对二假设比较，令 \(C_{MS}\) 为旧状态仍在却判搬走的损失、\(C_{SM}\) 为搬走却保留的损失，则

\[
\frac{P(H_M\mid Y)}{P(H_S\mid Y)}
=\frac{q_\ell}{1-q_\ell}\frac{p(Y\mid H_M)}{p(Y\mid H_S)}
>\frac{C_{MS}}{C_{SM}}. \tag{M4}
\]

这是要实现的后验比较。当前 \(\log99\) 对应对象缺席序贯检验的既有证据门；逐表面多数票对应局部对称错误代价及平票保留。两者比较的随机变量和错误事件不同，不能把每个现有常数都说成 99 的推导。M3 是同一准则；旧代码尚未联合计算 M1–M4，局部代价和近似如何连接必须逐项验证。后文明确区分已成立的概率计算、待推广的硬近似和确定性执行契约，不能以公式命名代替算法推广。

物化的“暂存”也有输出损失。设换址后验为 p，拼合在持续/换址下的代价为 `(0,C_U)`，仅显示旧状态的暂存代价为 `(C_V,C_N+C_G)`，其中分别计入遗漏新视角、遗漏真实新址和保留旧址残影。共同风险比较给出 `p(C_U−C_N−C_G)≤(1−p)C_V` 才选择拼合。当前对称关联边界还需推导这些动作代价之间的关系，并同时满足来源及原子交接约束。P08 在 I3 的 16.6 s、I13 的 18.7 s 输出遗漏了正确新址表面；P09 的一次额外漏检和 P10 已记录的 I11 确认残影增加也仍待严格处理。上述历史保留记录继续作为试验事实，逐输出验收门保持未通过。

衣柜另一面的无重叠是对应未定，\(p(Y\mid H_S)\) 仍可较大；新视角不应丢失。椅子搬到另一位置时，本会话已建立的几何与旧址穿透分别支持状态改变，旧位置退出 CURRENT 而保留历史。两种要求必须同时满足，不能用静态多视角补全抵消搬动残影。

## 3. 身份、状态与时间

每个物理实体 \(\ell\) 有独立于语义类别和 DSG node ID 的身份。实体的运行状态写作

\[
X_\ell=(\mathcal F_\ell,c_\ell,n_\ell,b_\ell,\mathcal A_\ell,\eta_\ell).
\tag{3}
\]

\(\mathcal F\) 保存时序片段；\(c\) 为 current；\(n\) 为候选；\(b\) 为继承实体的本会话子状态；\(\mathcal A\) 是已摄取观察区间；\(\eta\) 保存观测统计及运动先验。一个片段包含几何、包围盒、语义、出生、最近支持、传感器确认和关闭时间。

时间有明确角色：观察时间来自传感器；状态开始时间限定观测有效域；裁决时间标识执行轮次。合并片段时出生/首次观察取最早，支持/确认取最晚。关闭时间为

\[
t_{\rm close}=\max(t_{\rm decision},t_{\rm last\ support}).
\tag{4}
\]

片段按 `(first,last,node_id)` 摄取；重复区间在入口识别。首个观察打开 current。带可见运动历史的观察关闭原片段并打开新片段。继承实体先把本会话观察送入 \(b\)，让旧位置与新位置分别接受证据。同一会话内，体素重叠且其后仍有表面支持的观察可加入 current，其余进入候选。

设本轮支持数 \(S\)、反证数 \(C\)、可靠缺失门 \(g\in\{0,1\}\)，有效反证 \(C^*=gC\)。候选与 current 的扩张包围盒分离指示为 \(D\)。普通 current 的关闭条件为

\[
J=[C^*>S]\lor[D\land S=0].
\tag{5}
\]

`candidateWithinCurrentExtent` 实际检验两个世界 AABB 在一格容差下是否相交（不是候选完全包含于 current）。这个粗对应检验防止衣柜另一面或原位调整独自触发交接；它属于 M1 的同站点似然近似。式 (5) 的两条路径分别保留“旧位置确实被看空”和“同身份已在另一处被观测且旧址无支持”的需求。

关闭时提升可用候选；有直接支持时更新确认时间。候选时间已到且物体具静态先验或共享表面时合入当前片段。

继承状态还使用本会话已建立的实体几何：实体具运动倾向、本会话可靠样本至少 30、且超过一半顶点距旧表面顶点大于 0.10 m 时，判定实体已在另一位置。此项与式 (5) 的有效反证共同驱动继承态退出；本会话 current 接任。运动倾向由配置语义、实际 D1 历史和已关闭片段提供。

终结按相同规则处理候选和本会话子状态，再把最后的状态物化进 DSG。几何合并执行当前基准的网格拼接；实体时间片段与几何存储分别保持各自含义。

源码：`session_core/src/state/persistent_object_state.cpp`、`src/adapters/physical_object_merge.cpp`、`src/adapters/backend_session.cpp`。

## 4. 同一测量的几何含义与物理证据

相机中心为 \(c_i\)，世界射线方向为 \(d_i(u)\)，径向测距为 \(r_i(u)\)。测量端点为 \(p_i(u)=c_i+r_i(u)d_i(u)\)。查询旧点 \(x\) 时

\[
q_i(x)=\|x-c_i\|,\qquad e_i(x)=r_i(\pi_i(x))-q_i(x).
\tag{6}
\]

光轴 Z 深度由相机模型转换到径向距离后比较。世界变换统一左乘；几何和测量使用同一坐标系。点证据使用式 (6)，体素积分使用其投影像素方向上的 projective 残差。

| 实测关系 | 物理实体证据 |
|---|---|
| 视野外或无有效深度 | unobserved |
| 测量在旧点前方 | occluded |
| 深度吻合且相同物理 ID | supported |
| 深度吻合且其他 ID / 背景 | replaced by other / background |
| 射线穿过旧点到达更远表面 | free space |

几何存在性允许任意身份的同位置测量提供支持；实体存在性同时检查物理身份。查询使用状态最后支持之后的实际测量；遮挡与视野外各自保留为观察条件。

物体样本按空间格去重，维护各样本的支持与穿透时间。可靠样本上的观空比例 \(f\) 由自身与总体历史拟合 \(p_{\rm present}(f)\)（Beta 密度），当前实现递推

\[
L^+=\max(0,L-w\log p_{\rm present}(f)),\quad
w=\min(1,N_{\rm fresh}/\max(1,N_{\rm reliable})),\quad
 g=[L^+>\log99].
\tag{7}
\]

式 (7) 已经是以 absent 的均匀密度为参照、以 present 的经验 Beta 密度为分母的单侧加权 CUSUM。\(\log99=\log((1-0.01)/0.01)\) 源于原实现的 Wald 错误预算；CUSUM、鲜样本权重、经验拟合和单侧裁剪共同构成现有近似。该来源不等于在相关表面样本上已证明严格 1% 错误率。保留此递推与阈值，只解释，不重造检验。其输出授权式 (5) 的反证进入裁决。通过后重置累计量；传感器总体统计随会话保存。标签统计保留在证据记录中，当前覆盖门使用几何项。

关闭物体对应的背景副本由 `closed_object_background.cpp` 查询实际后续深度：背景表面自身时间参与查询，同位置实测表面继续提供支持，最后几何支持之后的穿透才产生背景变化。静止物体同时参与背景和 private mesh 的既有表示由此协同更新。

## 5. 状态授权的会话末观测域

令 \(t_\ell\) 为本会话新开的当前状态首次观察时间，恢复基准从 registry 的 `track_first_seen` 读取，缺值时取 `birth_time`。早于 \(t_\ell\) 的本身份像素退出当前状态的融合。其他旧像素保留实测端点，自由空间受到当前物体首交 \(\lambda\) 限制。

体素积分设截断距离 \(T\)、projective 残差 \(\delta\)，测量的合法贡献域为

\[
\delta>-T\quad\land\quad(\delta\le T\ \lor\ \widetilde q<\lambda-T).
\tag{8}
\]

\(\widetilde q\) 是体素沿采样射线的投影距离。\(\lambda\) 先查当前物体三角面，缺少合格命中时使用实测端点体素首交。式 (8) 保留观测表面的局部带和当前物体之前的自由空间。

合法贡献进入会话末 `PresentTsdf`：

\[
F^+(x)=\frac{W(x)F(x)+\min(1,\delta/T)}{W(x)+1},\qquad W^+(x)=W(x)+1,
\quad P=\operatorname{MC}(F=0).
\tag{9}
\]

只在八角均已积分的 cube 提取表面。这里的 `PresentTsdf` 是既有会话末模块；在线融合继续调用 Khronos。新面按面心到当前物体三角面的最近距离关联身份，一个物体体素内继承对应物理 ID，其余归背景。

表面公差使用 \(\tau(h,q)=\max(h,\sigma(q))\)，\(h\) 是层体素的一半；\(\sigma\) 由当前表面与测量的距离分箱残差估计。跨视图深度尺度 \(s\) 由残差的稳健中位数拟合，当前与历史尺度共同定义旧表面的位移误差窗口。

源码：`session_core/src/surface/session_refusion.cpp`、`present_tsdf.cpp`、`triangle_grid.cpp`、`frame_archive.cpp`。

## 6. 旧表面延拓与一次装配

当前恢复基准对带身份、来源和时间的旧表面执行以下明确判定。直接表面支持 \(H\)、有效穿透 \(F\)、遮挡 \(B\)、截断带内遮挡 \(B_T\) 均来自第 5 节观测域。投影邻域的命中取有效支持，穿透要求有效采样均穿透；自由空间同时检查 \(\lambda\)。

直接观测的延拓条件写为

\[
K_{\rm obs}(x)=
\begin{cases}
[H\ge F],&H+F>0,\\
[B\ge2B_T],&H=F=0.
\end{cases}
\tag{10}
\]

平票和零证据延续旧表面。对旧点 \(x\)，设当前表面最近点 \(y\)、距离 \(d\)、最近有效 reaching 相机 \(c\)、量程 \(q\)，历史正尺度最大值为 \(s_A\)，本会话正尺度为 \(s_B\)。错位副本条件为

\[
D(x)=[s_A+s_B>0]\land\operatorname{reached}(x)
\land[2h<d\le\tau(h,q)+(s_A+s_B)q]
\land[(y-x)\cdot(c-x)>0].
\tag{11}
\]

它检验视线方向、当前表面对应与尺度误差窗。几何存储中精确相同的点面可以共享表示；式 (11) 则会改变表面选择，属于算法判定。

同身份内部判定用于已进入视野且离当前表面超过一个物体体素的旧点：沿固定 64 个方向查同 ID 当前表面的首交，按面法向计入 \(N_{\rm in}\)、\(N_{\rm out}\)，取

\[
I(x)=[N_{\rm in}>N_{\rm out}].
\tag{12}
\]

有 shown memory 时，旧面保留位为

\[
K(f)=\operatorname{stateValid}(f)\,
K_{\rm obs}(\operatorname{center}f)\,[\neg D(\operatorname{center}f)]
\prod_{v\in f}[\neg I(v)].
\tag{13}
\]

`stateValid` 对背景成立；物体要求 current 存在且该状态始于本会话之前。旧图只有推理几何时，恢复基准的后备路径对其中 memory 顶点执行内部判定，再与新表面装配。

本会话在线几何还提供 fill 候选：面心 cube 存在未积分角，且面心有实测支持时保留。最终几何按 fill、present、保留旧面的顺序装配，身份决定输出槽；属性按来源保存，新增顶点从同槽原几何取属性并截时。物体输出槽为空时保留输入槽，背景直接提交。全部结果先计算到局部数据，再写入最终地图。

式 (10)—(13) 保留当前恢复版的直接测量、近邻遮挡、错位副本及内部面判定。它们分别近似 M1 中的观测或对应关系，再由 M3 决定表面去留。推广必须逐项保留其真实需求，并用逐物体判定、中间快照和最终指标验证。

### 6.1 表面更新是同一状态下的几何推断

M1 对“旧状态是否结束”和“该旧表面是否仍有真实几何”查询不同边缘量：身份已搬走不意味着其后方的墙也消失。状态裁决限定合法观测域（R03–R06），TSDF 在该域估计当下几何，旧表面再根据同一测量和误差参数决定延拓。式 (9) 是已有等权截断残差均值；对固定合法贡献域，可写成对截断观测的平方损失最小化。截断、遮挡和状态域属于测量选择，不能因此宣称整个原始 RGB-D 似然已变成独立同分布高斯。

式 (10) 的直接票若采用对称二项测量模型，令 \(p>1/2\) 为一张有效票方向正确的概率，则“旧面应退出”对“旧面应保留”的对数似然比为 \((F-H)\log[p/(1-p)]\)；等先验、等局部错误损失产生现有多数规则，平票延续。这里不选新的 \(p\) 数值，它只说明多数规则的概率结构。带内遮挡的 \(2B_T>B\) 对应“近邻重复层”对“真实更深遮挡面”的同类比较。它只在 \(H=F=0\) 时生效：有直接测量时不能让由其派生的遮挡摘要重复投票。

式 (11) 对应同一表面在两次观测中的尺度错位解释：容差窗、到达视角、视线方向和近表面下界共同约束对应。\((s_A+s_B)q\) 是原实现取正尺度的保守误差窗，**不是**两个独立尺度噪声的方差相加，也不是严格的 \(|s_A-s_B|q\) 物理偏差。保留该机制处理旧拷贝躲在新表面后方的残影；概率推广应积分尺度/对应的不确定性，不能直接换成另一个较窄公式。式 (12) 的 64 方向是同身份新表面对旧点的内外解释，不是 64 次相机观测；在 M1 中应条件于已估计的新几何，不能把它们再当独立深度帧。

## 7. 终结、序列化与递归接续

在线变化检测在每个独立片段上完成；其后按物理 ID 归并逻辑实体。终结最后一次归并后重新处理新摄取片段并刷新射线索引，然后执行会话末表面更新，最终时间与最后 ACK 输入一致。

### 7.1 推理顺序、原生接入与持久化的逐项对应

工程契约决定 M1 看到了哪些数据、M2 恢复了哪些状态、M3 何时提交动作。它们是统一推断的实现条件；数组越界保护、文件完整性、消息 ACK、精确身份键不应改成概率。Khronos 原生算法及外部代码保持只读。
