## 1. 系统目标与完整递推

D1 是持续可见的运动，D2 是同一运行内的隐藏变化，D3 是跨 session 空档的隐藏变化。每个 session 启动新进程和短期跟踪器，恢复前序地图后继续执行完整 D1/D2。

设会话输入为 \(Y_k=\{(t_i,I_i,D_i,L_i,T_i)\}_{i=1}^{n_k}\)，分别包含时间、颜色、深度、物理身份和相机位姿；语义类别另行保存。持久状态为 \(P_k\)。完整算法的组合为

\[
\boxed{
P_k=\operatorname{Save}\!\left[
\operatorname{Surface}\!\left(
\operatorname{Drain}\!\left[
\operatorname{Fold}_{Y_k}(\operatorname{Khronos}+\operatorname{IdentityEvidence},
                         \operatorname{Load}(P_{k-1}))
\right],Y_k\right)\right].
\tag{1}
\]

式中 `Khronos + IdentityEvidence` 表示已有在线执行链在确定的回调点组合项目扩展。`Drain` 排空处理队列、异步变化检测和最后到达的物体片段；`Surface` 用最终状态限定观测，再更新会话末表面；`Save` 提交下一进程读取的状态。

初值 \(P_0=\varnothing\)，同一运行入口完成 \(P_0\to P_A\to P_B\to P_C\)。下一会话读紧邻前序状态；旧 session 的完整输入视频和整条快照序列留在原产物中。

研究验收同时衡量三个目标：

\[
Q_{\rm current}(A\to B)\ge Q_{\rm current}(B),\quad
I_{\rm persistent}(A\to B)>I_{\rm persistent}(B),\quad
\operatorname{Ghost}_{\rm current}(A\to B)=0.
\tag{2}
\]

这是评价目标。准确度按真实 RGB-D/GT 检查，信息增益来自未重观测区域的保留、静态多视角补全和时间历史。移动物体旧状态进入 HISTORY，新位置进入 CURRENT；全过程和最终时刻分别检查。

### 1.1 统一模型：一个测量似然、一个持续性先验、一个决策准则

本节先写完整的推断问题，再说明现有每个状态机制是其中哪一项，最后用同一组量解释五个必须同时成立的场景。逐条试验的数值、回退理由和对照记录在 `reports/rewrite_goal/patch_list.csv` 及其引用的 JSON；README 只保留模型与公式。

**状态与三个解释。** 对物理身份 \(\ell\)，已提交的 CURRENT 状态记为 A（几何 \(G_A\)、开始时间、最后实测支持）；本会话尚未与 A 关联的同身份观测记为 N（同会话为 `observed_new`，继承态为会话子状态 `b_session` 的 CURRENT）；其余片段是 HISTORY。一次**观测事件** \(e\) 是一轮变化检测：冻结一份到 \(t_e\) 为止的证据快照，依次执行验证、摄取/物化，终局时再执行终结。对 A 与 N 只有三种解释：

- \(S\)：A 仍在原处，N 是 A 的其他表面（另一面、补全）；真实当前几何为 \(G_A\cup G_N\)。
- \(M\)：A 已结束，N 是继任状态（或继任尚未被观测到）；真实当前几何为 \(G_N\)。
- \(U\)：N 不是 \(\ell\) 当前状态的有效重建（轮廓碎片、偶发错标）；真实当前几何为 \(G_A\)。

**测量似然。** 全部推理以同一批有时间和来源的实际 RGB-D 测量为条件：

\[
\mathcal L_t(X_t)=p(Y_t\mid X_t,Y_{<t})
=\sum_{a,v,z}\int p(Y_t,a,v,z\mid X_t,\Theta)\,
 p(\Theta\mid Y_{<t})\,d\Theta . \tag{M1}
\]

\(a\) 是测量与状态/表面的对应，\(v\) 是可见、遮挡、未覆盖等观测条件，\(z\) 是表面样本是否可靠，\(\Theta\) 是深度误差、标签漏检和样本可靠性参数。深度项是同一首回波模型：令 \(\rho_a(X)\) 为射线与假设表面 \(a\) 的距离，\(F_q\) 为该量程下测距残差分布，\(h\) 为表面离散半尺度，

\[
g_{q,h}(e)=\frac{F_q(e+h)-F_q(e-h)}{2h},\qquad
p(r,\widehat\ell\mid X,\Theta)
=\sum_a\pi_a(X)\,g_{q,h}\!\left(r-\frac{\rho_a(X)}{1+s}\right)
 Q(\widehat\ell\mid\ell_a,r,a). \tag{M1a}
\]

\(\pi_a\) 含足迹内对应与首回波可见性，\(Q\) 是已关联端点的身份识别/漏标。遮挡由更近表面生成回波，被遮挡表面的状态被积分掉，似然比为 1；视野外和无效读数同样为 1。现有代码把同一批读数分成互不重叠的四组摘要，每组对“M 对 S”给出一个似然比；相加时同一读数只用一次：

| 组 | 读数 | 似然比 | 现有计算 |
|---|---|---|---|
| \(Y_A\) 旧址 | A 最后支持之后投影到 \(G_A\) 的读数 | \(\Lambda_A\) | 端点关系 M1m；可靠样本看穿比例的单侧 Beta/均匀序贯似然比 (7)；同一批射线的支持票 \(S\)、反证票 \(C\)；区间有限样本似然 M1e |
| \(Y_N^{\rm geo}\) 新几何 | N 的表面相对 \(G_A\) 的位置 | \(B_{M:S}\in[0,2]\) | 共享支持 M1c、范围 M1d、离址比例 M1g 与有效格数 → M1h |
| \(Y_N^{\rm cov}\) 新覆盖 | N 自己表面上的逐次观测 | \(L_{U:N}\) | 缺席检验在 N 的表面上算出的逐次有限样本似然比之积（M1b/M1e 同一量）：N 是否是该身份的有效表面（U 对有效）。没有标定观测通道的调用（单元夹具）沿用 M1f 计数似然 |
| \(Y_{D1}\) 跟踪 | 原生跟踪器运动标志 | \(\infty\) | 原生只输出布尔值，按其定义作为确定的换状态观测 |

\(Y_A\) 与 \(Y_N\) 来自不同位置的像素；\(Y_N^{\rm geo}\) 与 \(Y_N^{\rm cov}\) 回答同一 N 的两个不同问题：在哪里（S 对 M）与是否有效（U 对有效）。所以 M1c/M1d/M1g 不在同一判定中相乘；几何因子只进 S/M 的赔率，覆盖似然只进 U 的赔率项，二者在同一后验 \(P(S)\propto(1-q)v,\ P(M)\propto qvB_{M:S},\ P(U)\propto(1-v)L_{U:N}\) 中各占其位（U 的几何取 M1h 的无约束参照模型，因子 1）。\(v\) 是会话副本的先验有效率，没有实测率，取无差别值 1/2。对可靠表面，在位穿透率 \(f\sim{\rm Beta}(\alpha,\beta)\) 时有限覆盖的计数似然为

\[
p(k\mid n,S)=\binom nk\frac{B(k+\alpha,n-k+\beta)}{B(\alpha,\beta)},
\qquad p(k\mid n,M)=\frac{1}{n+1}, \tag{M1b}
\]

后者是原 absent 均匀比例模型。现有 (7) 用连续比例的 Beta 密度并作单侧处理，以 Page 统计量对变化时刻取最大（P25 第 3 次）。

**持续性先验。** 对身份 \(\ell\)，\(q_\ell\) 是相邻两次有效观察之间换状态的概率，\(K_\ell\) 是换状态后的分布：

\[
p(X_{\ell,t}\mid X_{\ell,t-1},q_\ell)
=(1-q_\ell)\,\delta_{X_{\ell,t-1}}(X_{\ell,t})
+q_\ell K_\ell(X_{\ell,t}\mid X_{\ell,t-1}). \tag{M2}
\]

延续允许新测量补全该状态的几何；\(K_\ell\) 只接收新状态自己的观测，不把旧形状搬到新位置。每身份同一时刻至多一个 CURRENT，历史不并入另一状态，未来测量不支持过去。没有有效观测时不推进一次变化试验。类别、物体自身历史通过层次 Beta 进入同一个 \(q\)：同类其他物体给 \((m_c,u_c)\)，同组其他类别给 \((m_g,u_g)\)，物体自身已解决的关系给 \((m_\ell,u_\ell)\)（`closeCurrent` 记变化 \(m\)，确认吸收或终局同状态记延续 \(u\)；D1 首片段单记一次变化），类别名单只作一条方向意见 \(o c\)：

\[
\mu_g=\frac{m_g+1/2+oc}{m_g+u_g+1+o},\quad
 a_c=\kappa\mu_g+m_c,\quad b_c=\kappa(1-\mu_g)+u_c,\quad
 q_\ell=\frac{a_c+m_\ell}{a_c+b_c+m_\ell+u_\ell},\quad \kappa=1+o.\tag{M2a}
\]

\(1/2\) 是 Bernoulli 的 Jeffreys 参考测度；冷启动可动类均值 3/4、持续类 1/4，无类别表 1/2。**读取时刻**：\(q_{\ell,e}=E[q_\ell\mid H_{<e}]\)。同一事件内所有身份、所有动作读同一份事件前历史；本事件解决的关系只对后续事件可见。物理 ID 编号、遍历顺序、同一时刻的重复回调和会话结束都不是测量，不能改变 \(q\)。实现上每轮变化检测开始时冻结各身份已解决的变化/延续计数与类别，验证、摄取/物化和终结都读该快照，本轮解决的关系只对下一轮可见（P09 第 3 次）；此前交换两物体编号可让 \(q\) 由 0.75 变 0.5，现在编号置换不变。

**决策准则。** 每个动作取后验期望损失最小：

\[
\pi_t(X)\propto\mathcal L_t(X)\int p(X\mid X',q)\pi_{t-1}(X',q)\,dX'\,dq,
\qquad a_t^*=\arg\min_{a\in\mathcal A(X)}\mathbb E_{\pi_t}[C(a,X)]. \tag{M3}
\]

对二假设，\(\frac{P(M\mid Y)}{P(S\mid Y)}=\frac{q_\ell}{1-q_\ell}\frac{p(Y\mid M)}{p(Y\mid S)}>\frac{C_{MS}}{C_{SM}}\)。 \tag{M4}

损失只有一张表，两类条目：
- **关联与显示**：显示表面与真实当前表面的对称差，同一表面测度、单位损失。设 \(a=\mu(G_A\setminus G_N)\)、\(b=\mu(G_N\setminus G_A)\)，三种显示的风险为 \(R_{\cup}=p_Ma+p_Ub\)、\(R_{A}=p_Sb+p_M(a+b)\)、\(R_{N}=p_Sa+p_U(a+b)\)，于是 \(R_A-R_\cup=(1-2p_U)b\)、\(R_N-R_\cup=(1-2p_M)a\)：不受约束时，只有 \(p_U>1/2\) 才只显示旧址，只有 \(p_M>1/2\) 才只显示新址，否则显示并集；实际可行集由下文动作 4 的约束限定。比较边界是后验 1/2，即 M4 中损失比 1。
- **无继任观测而结束状态**：只凭旧址读数把身份从 CURRENT 删去，与“继续保留”的损失比 99:1，来自既有缺席检验的名义 1%/1% 错误预算（282573a），是声明的损失比而非由数据拟合。

代码中所有判定边界都是这两条损失比在 M4 中的结果：\(\log 99\)、\(q B>1-q\)、\(1-q\ge qB\)、多数票。

**由同一准则得到的动作。**

1. **旧址看空即结束 A**（S12/S13/S14，式 5）：(7) 的后验几率过 \(\log99\)，再由同一批射线的反证多于支持确认。继承来的 CURRENT 检验的是 A→本会话这一未决关系，它的先验 \(q\) 只配“会话开始前已变化”这一候选（首窗的 \(L_t^{\rm pre}\)），会话内的变化没有声明的危险率，由 Page 统计量单独检验；本会话新生的状态没有跨会话关系，先验项为 0（P14 收紧，2026-10-05）。多数票是对称投票模型下精确的后验符号：反证 \(C\)、支持 \(S\) 的对数似然比为 \((C-S)\log[p/(1-p)]\)，对任何票可靠度 \(p>1/2\) 只取决于 \(C-S\)。两摘要来自同一批射线，取“二者都成立”而不相乘。
2. **接任**（A→HISTORY，N→CURRENT）：接任在 S 与 U 下都错、不接任在 M 下错，同一表面损失，所以继承态接任当且仅当 \(P(M)>P(S)+P(U)\)，即 \(qB_{M:S}>(1-q)+\frac{1-v}{v}L_{U:N}\)（M1h、M1e，P05 第 4 次）；\(q\) 只作 A→N 关系的变化先验，不再兼作“已建立”的先验，原来的两条件 AND 与 30 样本尺度不再出现；同会话要求 N 在异址 \(q(1-p_{\rm ext})>(1-q)p_{\rm ext}\)（M1d）且旧址本轮无同身份支持。在“一身份一处”约束下，M 时同身份端点不可能落在旧面上（N 与旧址重叠的情形由 M1e 单独处理），一票支持即排除 M；\(S=0\) 是这一约束给出的条件，不是可调门槛。
3. **合并**（N 并入 A）：A 本轮有实测支持且未被看空时吸收 N，需 \(1-q\ge qB\)（M1k/M1l）；同会话摄取用共享支持 M1c，并排除区间内被看空的旧状态（M1e）。
4. **显示**（每个在线输出的物化）：可行的显示动作受两条既有约束限定（M3 的 \(\mathcal A(X)\)）：输出是已提交状态的投影——状态机提交接任之前，该身份的 CURRENT 仍是 A（physical_presence_recursion 测试）；不同状态不能拼成一个当前几何（S15）。在可行集 {并集, 只旧} 内，并集只在 \(S\) 为 MAP 时可行，因此 \(1-q\ge qB\) 时显示 \(G_A\cup G_N\)，否则只显示 \(G_A\)（M1i）；新址在接任提交的那一轮出现在输出中。去掉第一条约束、在 \(M\) 为 MAP 时先显示 \(G_N\) 的无约束贝叶斯显示是 P08 第二次试验，未提交即被该既有测试否定。
5. **终局**：同一后验、同一规则；会话结束不是测量。先执行已成立的看空与接任，再按 \(1-q\ge qB\) 合并；剩余 \(M\) 为 MAP 而未建立的 N 归档为 HISTORY，不删除、不并集（S18）。

**已实现的各项（公式与条目）。** 每项的逐物体对照和验收见 patch_list 对应行。

- P01（M2a）：原“高可动”的三条 OR 改为同一个 \(q\)；类别名单只给先验方向。
- P02（M1c）：共享体素的量化相位对应概率 \(p_{xy}=\prod_j(1-|x_j-y_j|/r)_+\)，\(p_\cap=1-\prod_v(1-\max_w p_{x_vy_w})\)；同状态当且仅当 \((1-q)p_\cap>q(1-p_\cap)\)。
- P03（M1d）：AABB 间隙无格界事件 \(p_{\rm ext}=\prod_j(1-g_j/r)_+\)；异址当且仅当 \(q(1-p_{\rm ext})>(1-q)p_{\rm ext}\)。
- P04（M1e）：区间内可靠样本的有限样本缺席似然 \(\ell_i=w_i[-\log(n_i+1)-\log p(k_i\mid n_i,S)]\)，单侧；旧址被看空当且仅当无同身份支持且 \(\operatorname{logit}q+\sum_i\ell_i>\log99\)。
- P05（M1h + M1e，第 4 次）：接任当且仅当 \(qB_{M:S}>(1-q)+\frac{1-v}{v}L_{U:N}\)，\(\log L_{U:N}=\sum_{\rm looks}w[-\log(n+1)-\log p(k\mid n,S)]\) 取 N 自己表面上的逐次缺席似然比，\(v=1/2\)。真实 B 395 次、合成 213 次接任判断与旧的两条件规则逐次相同。只有没有标定观测通道的单元夹具仍用 M1f 计数契约 \(\ell_E={\rm sgn}(n-K)[n\log(n/K)-n+K]\)（\(K=30\)），与 observedEmptySince 的计数分支同理。
- P06（M1g）：两表面离散误差各为 \(U(-r/2,r/2)\)，对应事件 \(d+\varepsilon\le T\) 的三角 CDF \(p_{\rm near}(d)\)；\(T=0.10\) m 为状态容差，\(r\) 为地图分辨率。最近点搜索先查自身格（第 2 次，输出不变），使每轮耗时回到原实现量级。

(b) 在位分布（P26、P27；P25 的 min(30, 可靠数) 与 P21 的在位门同属此块）——污染层次模型核心分量的近似。一次观测的看穿比例在“在场”下服从一个两部分分布：核心是物体自身的读数噪声，尾部是换视角、遮挡边缘造成的跳变（相邻两次变化的标准差 0.149，MAD 标准差只有 0.059，99% 分位 0.53）。尾部与“缺席”的高比例重叠，所以检验只拿核心当在场密度，尾部的质量留给缺席一侧，再由同批射线的多数票把关。代码中的各项都是这个核心分量的估计：MAD 给出核心尺度（对正态核心一致）；max(v0, ·) 规定物体自身的核心散布不低于总体核心散布，因为少数几次在位观测估出的散布偏窄；三伪观测收缩与“三次以上才用自身统计”是核心均值的收缩估计；min(30, 可靠数) 只在比例的二项抽样方差不超过核心方差时才把比例当作测量。近似的位置与误差方向：在场跳变落入尾部时，单次观测的缺席证据被高估，偏向提早提交，代价由射线确认 \(C>S\) 截断；判过样本太少的观测被整体丢弃而非折算，偏向漏用证据（如合成 B 的 pillow_0004/0005，三次 100% 看穿均未计分）。2026-10-05 在精确重放上试过的七种推导各至少让一处 GT 核实的判定变差，均已否决（experiments_20261005.csv）：Student-t 经验贝叶斯后验预测（重尾吸收缺席质量，真实 B 丢 5/6 正确关闭）；经验贝叶斯收缩数 \(\sigma_w^2/\tau^2\)（合成 inst 48 正确关闭推迟）；Beta-二项有限样本计分（合成 inst 68 推迟 87 s 的原因是双重折扣——计数似然已按 n 个判定样本计证据，Page 权重又按 n/可靠数再折，被折的那次观测射线 S0/C81 是真信号；改为单次折扣后 inst 68 按时关闭，但真实 A 末 8 s 对 GT 静止的 inst 7、10 提交：距离 2.8–3.5 m、越带量 0.9–1.5 m 的远距离掩码/深度串扰，射线同源误差；浓度用 MAD 矩估计或最大边际似然 \(c\approx4.3\) 都一样，否决原因是在位比例随观测几何变化）；以检验自身后验作学习门（选择偏差，真实 A 误关 10 处）；身份通道二项/Beta-二项混合在位门（真实数据中把“部分识别”当作一类，或把已搬走物体的旧址判为在位）；逐样本独立模型（同一观测设计效应约 180）。共同根因是同一观测内样本的空间相关与视角重尾；显式建模需要观测内样本位置的空间结构（下一轮）。 2026-10-05 夜补充：单次折扣的 Beta-二项（浓度取最大边际似然 c≈4.3）消除了合成 inst 68 的推迟（原因是双重折扣），但在真实 A 末对 GT 静止的 inst 7、10 误提交（远距离掩码/深度串扰，整次观测越带）；按距离箱条件化在位分布既不消除这些误提交又在真实 A 新增一次误关。在位比例的几何依赖不是单一距离变量能刻画的，找到不靠调参的形式之前维持现状。

## 3. 身份、状态与时间

每个物理实体 \(\ell\) 有独立于语义类别和 DSG node ID 的身份。实体的运行状态写作

\[
X_\ell=(\mathcal F_\ell,c_\ell,n_\ell,b_\ell,\mathcal A_\ell,\eta_\ell).
\tag{3}
\]

\(\mathcal F\) 保存时序片段；\(c\) 为 current；\(n\) 为候选；\(b\) 为继承实体的本会话子状态；\(\mathcal A\) 是已摄取观察区间；\(\eta\) 保存观测统计及运动先验。一个片段包含几何、包围盒、语义、出生、最近支持、传感器确认和关闭时间。

时间有明确角色：观察时间来自传感器；状态开始时间限定观测有效域；裁决时间标识执行轮次。合并片段时出生/首次观察取最早，支持/确认取最晚。关闭时间为

\[
t_{\rm close}=\max(t_{\rm decision},t_{\rm last\ support}).
\tag{4}
\]

片段按 `(first,last,node_id)` 摄取；重复区间在入口识别。首个观察打开 current。带可见运动历史的观察关闭原片段并打开新片段。继承实体先把本会话观察送入 \(b\)，让旧位置与新位置分别接受证据。同一会话内，体素重叠且其后仍有表面支持的观察可加入 current，其余进入候选。

设本轮支持数 \(S\)、反证数 \(C\)、可靠缺失门 \(g\in\{0,1\}\)，有效反证 \(C^*=gC\)。候选与 current 的扩张包围盒分离指示为 \(D\)。普通 current 的关闭条件为

\[
J=[C^*>S]\lor[D\land S=0].
\tag{5}
\]

`candidateWithinCurrentExtent` 实际检验两个世界 AABB 在一格容差下是否相交（不是候选完全包含于 current）。这个粗对应检验防止衣柜另一面或原位调整独自触发交接；它属于 M1 的同站点似然近似。式 (5) 的两条路径分别保留“旧位置确实被看空”和“同身份已在另一处被观测且旧址无支持”的需求。

关闭时提升可用候选；有直接支持时更新确认时间。候选出生不晚于支持且 \(1-q\ge qB\)（M1k/M1l）时合入当前片段。

继承状态还使用本会话的实体几何：\(qB_{M:S}>(1-q)+\frac{1-v}{v}L_{U:N}\)（M1g/M1h，\(L_{U:N}\) 为 N 自己的逐次观测似然比）时判定实体已在另一位置。此项与式 (5) 的有效反证共同驱动继承态退出；本会话 current 接任。\(q\) 由 M2a 给出，类别、D1 历史和已关闭片段只通过它进入。

终结按相同规则处理候选和本会话子状态，再把最后的状态物化进 DSG。几何合并执行当前基准的网格拼接；实体时间片段与几何存储分别保持各自含义。

源码：`session_core/src/state/persistent_object_state.cpp`、`src/adapters/physical_object_merge.cpp`、`src/adapters/backend_session.cpp`。

## 4. 同一测量的几何含义与物理证据

相机中心为 \(c_i\)，世界射线方向为 \(d_i(u)\)，径向测距为 \(r_i(u)\)。测量端点为 \(p_i(u)=c_i+r_i(u)d_i(u)\)。查询旧点 \(x\) 时

\[
q_i(x)=\|x-c_i\|,\qquad e_i(x)=r_i(\pi_i(x))-q_i(x).
\tag{6}
\]

光轴 Z 深度由相机模型转换到径向距离后比较。世界变换统一左乘；几何和测量使用同一坐标系。点证据使用式 (6)，体素积分使用其投影像素方向上的 projective 残差。

| 实测关系 | 物理实体证据 |
|---|---|
| 视野外或无有效深度 | unobserved |
| 测量在旧点前方 | occluded |
| 深度吻合且相同物理 ID | supported |
| 深度吻合且其他 ID / 背景 | replaced by other / background |
| 射线穿过旧点到达更远表面 | free space |

几何存在性允许任意身份的同位置测量提供支持；实体存在性同时检查物理身份。查询使用状态最后支持之后的实际测量；遮挡与视野外各自保留为观察条件。

物体样本按空间格去重，维护各样本的支持与穿透时间。一轮对账是一次观测 \(i\)：可靠样本中被判的 \(n_i\) 个里有 \(k_i\) 个被看穿，比例 \(f_i=k_i/n_i\)。absent 时 \(f\) 均匀；present 时 \(f\sim p_{\rm present}\)，即由物体自身在位观测向物体总体收缩后投影的 Beta 密度（单侧）。序贯检验是对变化时刻 \(s\) 取最大的 Page 统计量：

\[
L_t=\max\Bigl(0,\ \max_{s\le t}\sum_{i=s}^{t}w_i(s)\,[-\log p_{\rm present}(f_i)]\Bigr),\quad
w_i(s)=\min\Bigl(1,\frac{N_i^{\rm first}(s)}{\max(1,N_{\rm reliable})}\Bigr),\quad
g=\Bigl[\max\Bigl(\log\frac{q_A}{1-q_A}+L_t^{\rm pre},\ L_t\Bigr)>\log99\Bigr].
\tag{7}
\]

\(N_i^{\rm first}(s)\) 是观测 \(i\) 判过、而在 \(s\) 到 \(i-1\) 之间未被判过的可靠样本数：对一个候选变化时刻，每个样本只作证一次，一个候选的总权重至多是整个物体，同一小块表面反复看多次不会变成多份全物体证据。权重与 \(s\) 无关时上式就是递推 \(L^+=\max(0,L+w\,\ell)\)；权重依赖 \(s\) 时递推只保留最早的起点，权重被一次未过阈的累积耗尽后，后来真正的移走也只剩约十分之一的权重（P25 第 3 次修正，合成 B 的 flower_0003）。所以显式对 \(s\) 取最大，它不小于递推值。\(\log99=\log((1-0.01)/0.01)\) 是声明的 Wald 错误预算；它不等于在相关表面样本上已证明严格 1% 错误率。\(L_t^{\rm pre}\) 是首窗第一个候选（本会话该状态的第一次计分观测之前已变化）的累积比值，在位证据可以把它压到负值；没有计分观测时比值为 1，后验等于先验。\(q_A\) 只对继承来的 CURRENT 出现（它须由本会话支持才延续，检验的是 A→本会话关系）；一次提交即结束首窗，此后只剩会话内变化的检验。合成 B 的 pillow_0004/0005 各有 32/20 个可靠样本，三次观测全部看穿，但每次判过的只有 13/20/3 与 11/13/9 个，不足 min(30, 可靠数)，不评分；\(q_A\) 升到 0.99 后后验等于先验即过 \(\log99\)，射线反证 153/67 对支持 0 确认关闭（GT 两者在 A→B 间各搬动 2.4 m）。过阈即提交并清空全部候选；同一批射线的反证多于支持（式 5）才关闭状态。传感器总体统计随会话保存；标签不作证据（P28）。

关闭物体对应的背景副本由 `closed_object_background.cpp` 查询实际后续深度：背景表面自身时间参与查询，同位置实测表面继续提供支持，最后几何支持之后的穿透才产生背景变化。静止物体同时参与背景和 private mesh 的既有表示由此协同更新。

## 5. 状态授权的会话末观测域

令 \(t_\ell\) 为本会话新开的当前状态首次观察时间，恢复基准从 registry 的 `track_first_seen` 读取，缺值时取 `birth_time`。早于 \(t_\ell\) 的本身份像素退出当前状态的融合。其他旧像素保留实测端点，自由空间受到当前物体首交 \(\lambda\) 限制。

体素积分设截断距离 \(T\)、projective 残差 \(\delta\)，测量的合法贡献域为

\[
\delta>-T\quad\land\quad(\delta\le T\ \lor\ \widetilde q<\lambda-T).
\tag{8}
\]

\(\widetilde q\) 是体素沿采样射线的投影距离。\(\lambda\) 先查当前物体三角面，缺少合格命中时使用实测端点体素首交。式 (8) 保留观测表面的局部带和当前物体之前的自由空间。

合法贡献进入会话末 `PresentTsdf`：

\[
F^+(x)=\frac{W(x)F(x)+\min(1,\delta/T)}{W(x)+1},\qquad W^+(x)=W(x)+1,
\quad P=\operatorname{MC}(F=0).
\tag{9}
\]

只在八角均已积分的 cube 提取表面。这里的 `PresentTsdf` 是既有会话末模块；在线融合继续调用 Khronos。新面按面心到当前物体三角面的最近距离关联身份，一个物体体素内继承对应物理 ID，其余归背景。

表面公差使用 \(\tau(h,q)=\max(h,\sigma(q))\)，\(h\) 是层体素的一半；\(\sigma\) 由当前表面与测量的距离分箱残差估计，各箱取随机游走平滑后验（P37）。跨视图深度尺度 \(s\) 由残差的稳健中位数拟合（拟合相对 \(s=0\) 的对数似然增益超过 BIC 扣除才采用，P41），当前与历史尺度共同定义旧表面的位移误差窗口 \(\tau+(|s_{\rm now}|+\max|s_{\rm prev}|)q\)：缩放读数沿射线偏离 \(|s|q\)，与符号无关，两会话之差由三角不等式界定（P42；原式只取正部，负尺度关闭了检验）。

这里的 \(\sigma\) 是“读数相对当前重建表面”的条件残差尺度：只统计前向、深度有效且位于既有截断域内的绝对残差。当前表面也由这些深度构建，因此它不是已分离出来的独立传感器噪声；同一像素对应多个顶点时，直方图条目也不是独立测量数。R08 的半体素下界保护粗网格表面，max 保留两种误差保护作用，但尚不是卷积后验。推广 P37–P42 时须保留这种相关性和选择条件，不能直接把现有 \(\sigma\) 再与网格误差独立相加，或把它充当 P05–P08 的新片段可信度。源码、谱系及不可辨识反例见 `reports/rewrite_goal/C3_joint_calibration_contract_20261004.json`。

源码：`session_core/src/surface/session_refusion.cpp`、`present_tsdf.cpp`、`triangle_grid.cpp`、`frame_archive.cpp`。

## 6. 旧表面延拓与一次装配

当前恢复基准对带身份、来源和时间的旧表面执行以下明确判定。直接表面支持 \(H\)、有效穿透 \(F\)、遮挡 \(B\)、截断带内遮挡 \(B_T\) 均来自第 5 节观测域。投影邻域的命中取有效支持，穿透要求有效采样均穿透；自由空间同时检查 \(\lambda\)。

直接观测的延拓条件写为

\[
K_{\rm obs}(x)=
\begin{cases}
[H\ge F],&H+F>0,\\
[B\ge2B_T],&H=F=0.
\end{cases}
\tag{10}
\]

平票和零证据延续旧表面。对旧点 \(x\)，设当前表面最近点 \(y\)、距离 \(d\)、最近有效 reaching 相机 \(c\)、量程 \(q\)，历次会话深度尺度绝对值的最大值为 \(s_A\)，本会话深度尺度的绝对值为 \(s_B\)（代码取 \(|s|\)：尺度 \(1+s\) 使读数沿射线移动 \(|s|q\)，与符号无关）。错位副本条件为

\[
D(x)=[s_A+s_B>0]\land\operatorname{reached}(x)
\land[2h<d\le\tau(h,q)+(s_A+s_B)q]
\land[(y-x)\cdot(c-x)>0].
\tag{11}
\]

它检验视线方向、当前表面对应与尺度误差窗。几何存储中精确相同的点面可以共享表示；式 (11) 则会改变表面选择，属于算法判定。

同身份内部判定用于已进入视野且离当前表面超过一个物体体素的旧点：沿固定 64 个方向查同 ID 当前表面的首交，按面法向计入 \(N_{\rm in}\)、\(N_{\rm out}\)，取

\[
I(x)=[N_{\rm in}>N_{\rm out}].
\tag{12}
\]

有 shown memory 时，旧面保留位为

\[
K(f)=\operatorname{stateValid}(f)\,
K_{\rm obs}(\operatorname{center}f)\,[\neg D(\operatorname{center}f)]
\prod_{v\in f}[\neg I(v)].
\tag{13}
\]

`stateValid` 对背景成立；物体要求 current 存在且该状态始于本会话之前。旧图只有推理几何时，恢复基准的后备路径对其中 memory 顶点执行内部判定，再与新表面装配。

本会话在线几何还提供 fill 候选：面心 cube 存在未积分角，且面心有实测支持时保留。最终几何按 fill、present、保留旧面的顺序装配，身份决定输出槽；属性按来源保存，新增顶点从同槽原几何取属性并截时。物体输出槽为空时保留输入槽，背景直接提交。全部结果先计算到局部数据，再写入最终地图。

式 (10)—(13) 保留当前恢复版的直接测量、近邻遮挡、错位副本及内部面判定。它们分别近似 M1 中的观测或对应关系，再由 M3 决定表面去留。推广必须逐项保留其真实需求，并用逐物体判定、中间快照和最终指标验证。

### 6.1 表面更新是同一状态下的几何推断

M1 对“旧状态是否结束”和“该旧表面是否仍有真实几何”查询不同边缘量：身份已搬走不意味着其后方的墙也消失。状态裁决限定合法观测域（R03–R06），TSDF 在该域估计当下几何，旧表面再根据同一测量和误差参数决定延拓。式 (9) 是已有等权截断残差均值；对固定合法贡献域，可写成对截断观测的平方损失最小化。截断、遮挡和状态域属于测量选择，不能因此宣称整个原始 RGB-D 似然已变成独立同分布高斯。

式 (10) 的直接票若采用对称二项测量模型，令 \(p>1/2\) 为一张有效票方向正确的概率，则“旧面应退出”对“旧面应保留”的对数似然比为 \((F-H)\log[p/(1-p)]\)；等先验、等局部错误损失产生现有多数规则，平票延续。这里不选新的 \(p\) 数值，它只说明多数规则的概率结构。带内遮挡的 \(2B_T>B\) 对应“近邻重复层”对“真实更深遮挡面”的同类比较。它只在 \(H=F=0\) 时生效：有直接测量时不能让由其派生的遮挡摘要重复投票。

式 (11) 对应同一表面在两次观测中的尺度错位解释：容差窗、到达视角、视线方向和近表面下界共同约束对应。\((s_A+s_B)q\) 是两次尺度绝对值之和的误差窗（记忆元素来源会话未知，取历次最大），**不是**两个独立尺度噪声的方差相加，也不是严格的 \(|s_A-s_B|q\) 物理偏差；2026-10-05 的 DISPLACED_DIAG 显示窗内候选 80–95% 为重复表面（真实 B，1.25–3.25 m 各箱 92–95%），以 P53 边界替代则几何超差（见 P42/P47）。保留该机制处理旧拷贝躲在新表面后方的残影；概率推广应积分尺度/对应的不确定性，不能直接换成另一个较窄公式。式 (12) 的 64 方向是同身份新表面对旧点的内外解释，不是 64 次相机观测；在 M1 中应条件于已估计的新几何，不能把它们再当独立深度帧。

## 8. 输入、构建与运行契约

每个 session 提供原始 RGB-D、相机内参、`world_T_camera`、语义图和稳定实例图。可选 `T_session_to_world` 左乘位姿。原始 Z 深度单位米。图像尺寸、帧表、时间和 ID 均在启动时检查。

```text
rgbd/session_n/{timestamps.csv,Intrinsics.txt,<id>_color.png,<id>_depth.tiff,<id>_pose.txt}
semantics/session_n/<id>_segmentation.png
instance_labels/session_n/<id>_segmentation.png
instance_labels/session_n/manifest.json
alignment/session_n_to_world.txt
```

标签协议为 `packed_32SC1 = (semantic_id << 16) | physical_instance_id`，由 `input_labels_are_packed` 显式启用。物理 ID 0 表示背景。canonical 与历史实例后缀各自明确，同帧同义文件出现歧义时由预检报告。

真实 AB 的既定标注规则继续有效：I9 并入 I7、I20 仅 A、A 床面整体归 I1、I12 为背包实例。规则已固化进输入实例图及 manifest。原始 Synthetic AB 保持 30 Hz、680×480、A 4186/B 3555 帧；相机位姿和 semantic/instance 使用既定 GT 输入，GT 物体网格只参与评估。

标准构建与检查：

```bash
cd /home/jixian/Desktop/FT/session_update_baseline
./scripts/build_canonical.sh
./scripts/check_canonical_runtime.sh --require-built
```

构建验证 `ports/mapping_core`、`session_core` 和运行层源码指纹、安装位置及动态库来源，使用锁避免并发构建。当前 Hydra/PGMO 等研究依赖由 `/home/jixian/ros2_ws/install/setup.bash` 提供；Khronos 链接到本项目 canonical install。已有构建按脚本支持的 `--incremental` 方式更新。

生产入口为 `scripts/run_session.sh`，示例中的数据路径按实际数据填写：

```bash
./scripts/run_session.sh \
  --run-dir /path/to/session/rgbd \
  --semantic-dir /path/to/session/semantics \
  --instance-dir /path/to/session/instances \
  --output-state /path/to/new_state
# 后续 session 同一命令增加 --input-state /path/to/previous_state
# 不同坐标系增加 --world-transform /path/to/session_to_world.txt
```

每次运行启动一个 mapper，输出到新的状态目录。每帧通过 ACK 确认，终帧、保存时间和进程退出码对应；继承运行核对 output.initial 与 input 的推理 current。pure-B 使用独立标记的消融运行；生产更新只消费一份前序状态。C 直接消费 B。

唯一地图查看入口为 `scripts/view_ab_chain_4dmap.py`，配套原生 `4dmap_mesh_server`。压缩地图按时间片读取，保留完整时刻列表。datasets、权重、build/install、大地图与运行产物放在 Git 外，Git 保存源码、配置、许可证和紧凑记录。

## 9. 验收

**方法。** 同一源码从空图重跑全部会话，一次只运行一个建图器：真实 A→B→C（A 从空、B 读 A、C 读 B）、合成 A→B、3RScan 参考扫描 A→复扫 B、Bonn placing/removing/moving、TUM walking_xyz。固定指标与冻结的 48a3033 比较，容差 0.2 个百分点；逐身份决策流与上一版本对照，每一处差异按 GT 核对。凡影响会话 A 的改动，合成也从新 A 起跑。同一源码重复运行时，在线输出时刻随异步片段到达变化（真实 B 物体召回 97.82–98.22%，21 次记录），不以偶然高值作门限。起点证据（2026-10-03，canonical 编译与测试、真实 A/Bonn/TUM 复现、3RScan 指纹一致）见 `reports/rewrite_goal/progress.json`；历史设计归档于 `/home/jixian/Desktop/FT/archive/design_models_20260930/` 与本仓库 `archive/design_consolidation_20260930/`。
