## 2. What each piece is for (design → implemented → why → open)

The story: the TSDF update layer (fragments, object states, D1/D2/D3, observed-absence closure, free-space carving) carried to 3DGS. Rule for every piece: TSDF semantics, no tuned numbers, one code for both datasets.

- **T1 time-indexed Gaussians** (`alive_at`, `state_membership`): a keyframe renders and trains only the Gaussians alive at its stamp; rows end by state closure (`death_state`), by element evidence (`death_evidence`) or, for earlier sessions' rows, by GaME's prune (`death_prune`, P1). History check (accept.py) compares rows by uid between A's final map and B's start: P1 is required.
- **S3**: only this session's keyframes train (the fork never re-integrates earlier frames). Earlier keyframes are stored for the readout only.
- **Readout** (`_readout`): first echo (T first ≤ 0.5) from every stored keyframe (A's and B's) of the map alive at t, one point per 1 cm voxel. Same for rows 1/3/4.
- **Observed-absence closure** (core/l2): page statistic × judged fraction > ln 99 AND contradiction > support. **F1** (e243d0a): the present-beta mean is bounded by the variance floor's noise level (a < 1 degeneracy under the strict footprint look). Real log replay: decisions unchanged.
- **Element rule** (core/layer.py `_element_rule`): the TSDF free-space analogue; single-pixel verdict on/through per chosen stamp (1 Hz), one evidence step −ln p_miss per 10.8-s round from the round's last verdict, retire above ln 99; on-readings reset. **F2** (8db7d15): untracked-label rows are tested too. **F4** (c932e49): this session's object rows are tested too (carried-object trails). Open: on real depth its ends are ~85 % false (dark/reflective/thin surfaces read through systematically); the synthetic trail (plant 109: a full copy at the 114 s pose, 108k error points) needs two rounds of through-readings (21.6 s) but only had 4.5 s. **F4b** (per-observation accumulation, 3162539) removed the trail in replay but multiplied real false ends ×4.5 → withdrawn (rule = 3424c3d).
- **F3** (219b53b): carried rows' opacity is not optimised, never pruned by opacity/size, never densified or reset (GaME's competition deleted 34.5 % of A's rows in synthetic B, 97 % of them correct). **F3b** (f1e5730): where a frame reads a surface in front of a carried echo by more than the band, the surface is seeded now (re-integration). **F3c'** (5e722bd → 922bd6b): carried geometry is immutable (xyz/scale/rotation gradients and Adam moments blocked); colour trains (the TSDF integrates colour).
